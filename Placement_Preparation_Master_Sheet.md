### 1. String Processing with Query Replacements

- **Companies:** AMD
- **Years:** 2025
- **Category:** Strings
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `drive-download-20260904T140427Z-1-001/2025_09_08_AMD_Software.pdf`
- **Verified Link:** [String Processing with Query Replacements](https://codeforces.com/problemset/problem/1850/F)

#### Question

You are given a string S of length N and M queries of the form (x, y) where you must replace all occurrences of character x with y in sequential order. Determine the final string after processing all M queries.

#### Constraints

```
1 <= N, M <= 2 * 10^5
S and queries contain lowercase English letters
```

#### Approach

Rather than modifying the string S of length 200,000 in every query (which takes O(N * M) = 4 * 10^10 operations), maintain a mapping array of 26 characters: mapping[c] tracks which character 'c' ultimately turns into! Process the queries by updating the mapping array. After all M queries, transform the string S in a single O(N) pass.

#### Intuition

There are only 26 lowercase English letters. Updating a 26-element mapping array takes O(26) per query, reducing total time from O(N * M) to O(26 * M + N).

#### Algorithm

- Step 1: Initialize mapping[c] = c for all 26 lowercase letters.
- Step 2: For each query (x, y): for each char c in 'a'..'z', if mapping[c] == x, mapping[c] = y.
- Step 3: Build final string: for each char in S, replace with mapping[char].
- Step 4: Return the transformed string.

#### Java Solution

```java
public class Solution {
    public static String processQueries(String S, char[][] queries) {
        char[] map = new char[26];
        for (int i = 0; i < 26; i++) {
            map[i] = (char) ('a' + i);
        }

        for (char[] q : queries) {
            char from = q[0];
            char to = q[1];
            for (int i = 0; i < 26; i++) {
                if (map[i] == from) {
                    map[i] = to;
                }
            }
        }

        char[] sArr = S.toCharArray();
        for (int i = 0; i < sArr.length; i++) {
            sArr[i] = map[sArr[i] - 'a'];
        }
        return new String(sArr);
    }
}
```

#### Complexity

- **Time Complexity:** O(26 * M + N) = O(M + N)
- **Space Complexity:** O(26) auxiliary space

#### Sample Test Cases

**Test Case 1:**
- **Input:** `S = "redocta", queries = [['r','a'],['t','e'],['d','v'],['k','a'],['a','r']]`
- **Output:** `"revocer"`

**Test Case 2:**
- **Input:** `S = "abc", queries = [['a','b'],['b','c']]`
- **Output:** `"ccc"`

### 2. The Triplets Multiples of K

- **Companies:** AMD
- **Years:** 2025
- **Category:** Math
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `drive-download-20260904T140427Z-1-001/2025_09_08_AMD_Software.pdf`
- **Verified Link:** [The Triplets Multiples of K](https://atcoder.jp/contests/abc108/tasks/abc108_c)

#### Question

Find the number of triplets (A, B, C) of positive integers with 1 <= A, B, C <= N such that (A + B), (B + C), and (C + A) are all multiples of an integer K.

#### Constraints

```
1 <= N <= 2 * 10^5
1 <= K <= 2 * 10^5
```

#### Approach

Consider the condition modulo K: A + B = 0 mod K, B + C = 0 mod K, C + A = 0 mod K. Subtracting the first two gives A - C = 0 mod K => A = C mod K. Similarly, B = A mod K => A = B = C mod K. Then A + B = 2A = 0 mod K! This requires 2 * (A mod K) = 0 mod K. There are two cases: 1) A mod K == 0: Then A, B, C can each be any multiple of K in 1..N (count is floor(N / K)). Total triplets = floor(N / K)^3. 2) If K is even, A mod K can also be K / 2! Count of such numbers in 1..N is floor((N + K/2) / K). Total triplets adds floor((N + K/2) / K)^3.

#### Intuition

Pairwise sums being multiples of K forces all three numbers to have the exact same remainder r modulo K, where 2r = 0 mod K.

#### Algorithm

- Step 1: Count numbers <= N divisible by K: c0 = N / K.
- Step 2: Total triplets from c0 is c0^3.
- Step 3: If K is even: r = K / 2. Count numbers <= N with remainder r: c1 = (N - r >= 0) ? (N - r) / K + 1 : 0. Add c1^3.
- Step 4: Return total count.

#### Java Solution

```java
public class Solution {
    public static long countTriplets(long N, long K) {
        long c0 = N / K;
        long total = c0 * c0 * c0;

        if (K % 2 == 0) {
            long r = K / 2;
            long c1 = (N >= r) ? (N - r) / K + 1 : 0;
            total += c1 * c1 * c1;
        }
        return total;
    }
}
```

#### Complexity

- **Time Complexity:** O(1) time
- **Space Complexity:** O(1) space

#### Sample Test Cases

**Test Case 1:**
- **Input:** `N = 3, K = 2`
- **Output:** `9`

**Test Case 2:**
- **Input:** `N = 5, K = 9`
- **Output:** `0`

### 1. Valid Password Arrangements

- **Companies:** ARM
- **Years:** 2023
- **Category:** Strings
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `ARM/WhatsApp Image 2023-09-26 at 11.10.27 AM.jpeg`
- **Verified Link:** [Valid Password Arrangements](https://leetcode.com/problems/permutations-ii/)

#### Question

Given a password string S containing digits, uppercase, and lowercase letters. Generate all valid distinct arrangements of the password. Print the generated passwords in alphabetical order based on ASCII values: Numbers < Capital Letters < Lowercase Letters.

#### Constraints

```
1 <= S.length <= 8
S contains [0-9, A-Z, a-z]
```

#### Approach

Sort the characters in the specified ASCII order (which standard ASCII already satisfies: '0'..'9' is 48-57, 'A'..'Z' is 65-90, 'a'..'z' is 97-122). Then generate all unique permutations using backtracking with duplicate skipping (standard next_permutation or recursive swap).

#### Intuition

Standard ASCII values already place Digits < Uppercase < Lowercase. Generating lexicographical unique permutations matches the output requirement.

#### Algorithm

- Step 1: Sort characters of S.
- Step 2: Backtrack with used[] array to generate unique permutations in lexicographical order.
- Step 3: Skip duplicates: if arr[i] == arr[i-1] and !used[i-1], continue.
- Step 4: Collect all permutations and format space-separated.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static List<String> validArrangements(String s) {
        char[] arr = s.toCharArray();
        Arrays.sort(arr);
        List<String> res = new ArrayList<>();
        boolean[] used = new boolean[arr.length];
        backtrack(arr, used, new StringBuilder(), res);
        return res;
    }

    private static void backtrack(char[] arr, boolean[] used, StringBuilder sb, List<String> res) {
        if (sb.length() == arr.length) {
            res.add(sb.toString());
            return;
        }
        for (int i = 0; i < arr.length; i++) {
            if (used[i]) continue;
            if (i > 0 && arr[i] == arr[i - 1] && !used[i - 1]) continue;
            used[i] = true;
            sb.append(arr[i]);
            backtrack(arr, used, sb, res);
            sb.deleteCharAt(sb.length() - 1);
            used[i] = false;
        }
    }
}
```

#### Complexity

- **Time Complexity:** O(N! * N)
- **Space Complexity:** O(N! * N)

**Test Case 2:**
- **Input:** `s = "dd4"`
- **Output:** `["4dd", "d4d", "dd4"]`

### 2. Eliminate Rows with All Negative Ones

- **Companies:** ARM
- **Years:** 2023
- **Category:** Arrays

- **Source:** `ARM/WhatsApp Image 2023-09-26 at 11.10.27 AM (1).jpeg`

#### Question

Given an N x N square matrix of integers where some rows contain -1 in all columns. Write a program that prints the matrix rows after eliminating any row that consists entirely of -1.

#### Constraints

```
1 < N < 1000
-1 <= A[i][j] < 1000
```

#### Approach

Iterate through each row of the matrix. Check if all elements in the row are -1. If yes, skip the row; otherwise, keep/print the row.

#### Intuition

Linear scan of each row with an all-match check.

#### Algorithm

- Step 1: For each row in matrix:
- Step 2: Check if every element in row == -1.
- Step 3: If not all -1, add row to output list.
- Step 4: Return remaining rows.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static List<int[]> eliminateNegativeRows(int[][] matrix) {
        List<int[]> result = new ArrayList<>();
        for (int[] row : matrix) {
            boolean allNegativeOne = true;
            for (int val : row) {
                if (val != -1) {
                    allNegativeOne = false;
                    break;
                }
            }
            if (!allNegativeOne) {
                result.add(row);
            }
        }
        return result;
    }
}
```

#### Complexity

- **Time Complexity:** O(N^2)
- **Space Complexity:** O(N^2)

### 1. Compressing Array v2

- **Companies:** Adobe
- **Years:** 2023
- **Category:** Greedy
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `Adobe/Compressing array v2/IMG-20230721-WA0111.jpg`
- **Verified Link:** [Compressing Array v2](https://leetcode.com/discuss/interview-question/3807211/Adobe-OA)

#### Question

Given an array of integers a, in one operation select any two adjacent elements and replace them with their product, provided that their product <= k. Reduce the length of the array as much as possible by performing any number of operations. Return the minimum size.

#### Constraints

```
1 <= n <= 2 * 10^5
1 <= k <= 10^9
1 <= a[i] <= 10^9
```

#### Approach

Greedy stack simulation. Iterate through the array; if the current element can multiply with the top of the stack such that top * x <= k, merge them. Continue merging greedily as long as the new product with the new stack top <= k. The final stack size is the minimum length.

#### Intuition

Merging adjacent elements whenever product <= k is optimal because larger products absorb more elements without blocking future merges that are strictly commutative.

#### Algorithm

- Step 1: Use a stack of longs to represent merged elements.
- Step 2: For each element x in a: while !stack.isEmpty() and stack.peek() * x <= k, x = stack.pop() * x.
- Step 3: Push x onto stack.
- Step 4: Return stack.size().

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int getMinLength(int[] a, int k) {
        Stack<Long> stack = new Stack<>();
        for (int num : a) {
            long curr = num;
            while (!stack.isEmpty() && stack.peek() * curr <= k) {
                curr = stack.pop() * curr;
            }
            stack.push(curr);
        }
        return stack.size();
    }
}
```

#### Complexity

- **Time Complexity:** O(N) time
- **Space Complexity:** O(N) space

- **Output:** `3`

**Test Case 2:**
- **Input:** `a = [2, 2, 2, 2], k = 16`
- **Output:** `1`

### 2. Minimum Delivery Time

- **Companies:** Adobe
- **Years:** 2024
- **Category:** Binary Search
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `OA-2024/Adobe-IITG-Intern.pdf`
- **Verified Link:** [Minimum Delivery Time](https://leetcode.com/problems/minimum-time-to-repair-cars/)

#### Question

A developer has n messages to deliver. platformTime[i] is the time taken by the main platform to process message i. supportTime[i] is the time taken by a supporting service to process message i. Supporting services operate in parallel for all messages offloaded to them, while the main platform processes its assigned messages sequentially. Minimize the total time to deliver all messages, which is max(sum of platformTimes chosen, max supportTime of offloaded messages).

#### Constraints

```
1 <= n <= 2 * 10^5
1 <= platformTime[i], supportTime[i] <= 10^9
```

#### Approach

Binary search on the total time T. For a guessed time limit T: if any message has supportTime[i] > T, it CANNOT be offloaded to supporting services, so it MUST be processed by the main platform. Check if the sum of platformTimes of all mandatory platform messages <= T. Furthermore, if a message has platformTime[i] < supportTime[i], we can greedily keep it on platform as long as total platform time remains <= T.

#### Intuition

The feasibility function canAllCompleteWithin(T) is monotonic in T. Binary search over [1, sum(platformTime)] yields the optimal time.

#### Algorithm

- Step 1: Set low = 1, high = sum(platformTime).
- Step 2: While low <= high, set mid = low + (high - low) / 2.
- Step 3: Check feasibility: for each message, if supportTime[i] > mid, must take platformTime[i]. Sum platform times.
- Step 4: If mandatory platform sum <= mid, feasible = true, high = mid - 1; else low = mid + 1.
- Step 5: Return low.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static long getMinimumTime(int[] platformTime, int[] supportTime) {
        int n = platformTime.length;
        long low = 1, high = 0;
        for (int p : platformTime) high += p;
        long ans = high;

        while (low <= high) {
            long mid = low + (high - low) / 2;
            long platSum = 0;
            boolean possible = true;

            for (int i = 0; i < n; i++) {
                if (supportTime[i] > mid) {
                    platSum += platformTime[i];
                    if (platSum > mid) {
                        possible = false;
                        break;
                    }
                }
            }

            if (possible && platSum <= mid) {
                ans = mid;
                high = mid - 1;
            } else {
                low = mid + 1;
            }
        }
        return ans;
    }
}
```

#### Complexity

- **Time Complexity:** O(N log(sum(platformTime)))
- **Space Complexity:** O(1) auxiliary space

#### Sample Test Cases

**Test Case 1:**
- **Input:** `platformTime = [2, 1, 3, 4, 5, 6], supportTime = [5, 2, 4, 6, 1, 4]`
- **Output:** `5`

**Test Case 2:**
- **Input:** `platformTime = [9, 4, 9, 1, 6, 3, 8], supportTime = [5, 4, 1, 9, 1, 1, 6]`
- **Output:** `6`

### 3. Sort Roman Names

- **Companies:** Adobe
- **Years:** 2024
- **Category:** Sorting
- **Difficulty:** Easy
- **Type:** Coding
- **Source:** `OA-2024/Adobe-IITG-Intern.pdf`
- **Verified Link:** [Sort Roman Names](https://leetcode.com/problems/roman-to-integer/)

#### Question

Given a list of strings comprised of a name and a Roman numeral (1 to 50), sort the list first by name alphabetically, then by the decimal value of the Roman numeral.

#### Constraints

```
1 <= n <= 50
Roman numerals between 1 and 50
```

#### Approach

Parse each string into givenName and romanNumeral. Implement a Roman to Integer converter. Use Java's Arrays.sort with a custom comparator that first compares the name string, and if equal, compares the integer values.

#### Intuition

Standard compound sorting with string parsing and Roman numeral conversion.

#### Algorithm

- Step 1: Write helper romanToInt(String s) using standard symbol map (I=1, V=5, X=10, L=50).
- Step 2: Split each entry by space: name = parts[0], roman = parts[1].
- Step 3: Sort using Comparator: compare name.compareTo(other.name); if equal compare romanToInt(s1) to romanToInt(s2).
- Step 4: Return sorted array.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static String[] sortRoman(String[] names) {
        Arrays.sort(names, (a, b) -> {
            String[] p1 = a.split(" ");
            String[] p2 = b.split(" ");
            int cmp = p1[0].compareTo(p2[0]);
            if (cmp != 0) return cmp;
            return Integer.compare(romanToInt(p1[1]), romanToInt(p2[1]));
        });
        return names;
    }

    private static int romanToInt(String s) {
        Map<Character, Integer> map = Map.of('I', 1, 'V', 5, 'X', 10, 'L', 50);
        int total = 0;
        for (int i = 0; i < s.length(); i++) {
            int val = map.get(s.charAt(i));
            if (i + 1 < s.length() && val < map.get(s.charAt(i + 1))) {
                total -= val;
            } else {
                total += val;
            }
        }
        return total;
    }
}
```

#### Complexity

- **Time Complexity:** O(N log N * L)
- **Space Complexity:** O(1) auxiliary space

#### Sample Test Cases

- **Output:** `["Louis VIII", "Louis IX"]`

**Test Case 2:**
- **Input:** `names = ["Philippe I", "Philip II"]`
- **Output:** `["Philip II", "Philippe I"]`

### 4. Minimum Node Weight on Tree Simple Paths

- **Companies:** Adobe
- **Years:** 2024
- **Category:** Trees
- **Difficulty:** Hard
- **Type:** Coding
- **Source:** `drive-download-20260904T140501Z-1-001/Adobe /IMG-20240719-WA0005.docx`
- **Verified Link:** [Minimum Node Weight on Tree Simple Paths](https://leetcode.com/problems/sum-of-subsequence-widths/)

#### Question

Given an unweighted tree of n nodes and node weights weight[0..n-1]. For each pair of nodes (i, j) with i < j, find the minimum weight of a node that occurs on the simple path between i and j. Return the sum of these minimum weights over all pairs of nodes.

#### Constraints

```
1 <= n <= 10^5
1 <= weight[i] <= 10^9
```

#### Approach

Sort nodes in descending order of weight. Use Disjoint Set Union (DSU / Kruskal's idea): activate nodes from largest weight to smallest weight. When activating node u with weight W, union u with all already-active neighbors. For each already-active component C of size size[C] adjacent to u, the path between any node in C and any node in another active component or u has its minimum weight equal to W! Count of new pairs passing through u is accumulated and multiplied by W.

#### Intuition

Processing nodes from highest weight to lowest weight allows DSU component sizes to count exactly how many paths have node u as their bottleneck minimum.

#### Algorithm

- Step 1: Sort vertices by weight descending.
- Step 2: Maintain DSU with component sizes, initially all inactive.
- Step 3: When activating vertex u with weight W: track total paths formed between u and active adjacent components.
- Step 4: For each active neighbor component C: pairs_formed = size[C] * (1 + sum_previous_component_sizes). Add pairs_formed * W to total.
- Step 5: Union components together. Return total sum.

#### Java Solution

```java
import java.util.*;

public class Solution {
    static class DSU {
        int[] parent, size;
        DSU(int n) {
            parent = new int[n];
            size = new int[n];
            for (int i = 0; i < n; i++) { parent[i] = i; size[i] = 1; }
        }
        int find(int i) {
            if (parent[i] == i) return i;
            return parent[i] = find(parent[i]);
        }
        void union(int i, int j) {
            int rootI = find(i), rootJ = find(j);
            if (rootI != rootJ) {
                parent[rootI] = rootJ;
                size[rootJ] += size[rootI];
            }
        }
    }

    public static long sumMinWeightsAllPairs(int n, int[] weight, int[][] edges) {
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
        for (int[] e : edges) {
            adj.get(e[0]).add(e[1]);
            adj.get(e[1]).add(e[0]);
        }

        Integer[] nodes = new Integer[n];
        for (int i = 0; i < n; i++) nodes[i] = i;
        Arrays.sort(nodes, (a, b) -> Integer.compare(weight[b], weight[a])); // Descending

        DSU dsu = new DSU(n);
        boolean[] active = new boolean[n];
        long totalSum = 0;

        for (int u : nodes) {
            long w = weight[u];
            long currentSubtreeSize = 1;

            for (int v : adj.get(u)) {
                if (active[v]) {
                    int rootV = dsu.find(v);
                    totalSum += currentSubtreeSize * (long) dsu.size[rootV] * w;
                    currentSubtreeSize += dsu.size[rootV];
                    dsu.union(rootV, u);
                }
            }
            active[u] = true;
        }
        return totalSum;
    }
}
```

#### Complexity

- **Time Complexity:** O(N log N) sorting + DSU
- **Space Complexity:** O(N) space

#### Question

Amazon Academy has launched a new course on Quantum Physics. The course has n chapters, each chapter has memory[i] memory points, which a student gains or loses while reading that chapter. In order to study the ith chapter, the student must revisit all previous chapters. A student gains memory[0] + memory[1] + ... + memory[i] memory points for reading the ith chapter. The total memory points is the sum of memory points gained while reading each chapter. Students can read chapters in any order and want to maximize total memory points. Find the maximum total memory points ensuring all chapters are read.

#### Constraints

```
1 <= n <= 10^5
-10^3 <= memory[i] <= 10^3
```

#### Approach

Sort the array in ascending order. When reading chapter j at step j (0-indexed), its score contributes (n - j) times to the total sum. Therefore, placing larger elements later gives them higher multipliers. Specifically, the smallest element is multiplied by n, the second by n-1, ..., and the largest by 1? Wait: if chapter 0 is read first, it is revisited for every subsequent chapter! Thus, chapter 0 is included in every prefix sum (n times). So the largest element must be visited FIRST or LAST? Let's check: reading order c_0, c_1, ..., c_{n-1}: Chapter 0 is added in step 0, 1, ..., n-1 (n times). Chapter 1 is added in step 1, ..., n-1 (n-1 times). So chapter c_0 gets weight n, c_1 gets weight n-1, ..., c_{n-1} gets weight 1. To maximize sum c_i * (n - i), sort memory points in DESCENDING order!

#### Intuition

Earlier chapters are revisited in every subsequent chapter study session. By sorting the chapters in descending order, we assign the largest multipliers to the largest positive memory points, maximizing the total cumulative score.

#### Algorithm

- Step 1: Sort the array memory in descending order.
- Step 2: Initialize total_points = 0 and current_prefix_sum = 0.
- Step 3: Iterate through the sorted chapters, add the current chapter memory to current_prefix_sum, and add current_prefix_sum to total_points.
- Step 4: Return total_points as a 64-bit integer.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static long maxTotalMemoryPoints(int[] memory) {
        Arrays.sort(memory);
        // Reverse to descending order
        int n = memory.length;
        long totalPoints = 0;
        long currentPrefix = 0;
        for (int i = n - 1; i >= 0; i--) {
            currentPrefix += memory[i];
            totalPoints += currentPrefix;
        }
        return totalPoints;
    }
}
```

### 2. Minimum Possible Value of Maximum Parcels

- **Companies:** Amazon
- **Years:** 2024, 2025
- **Category:** Binary Search
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `onlyfans/Amazon /Set 2/Amazon_OA.pdf`
- **Verified Link:** [Minimum Possible Value of Maximum Parcels](https://leetcode.com/problems/minimized-maximum-of-products-distributed-to-any-store/)

#### Question

Amazon must optimally distribute extra parcels among delivery agents. Initially, there are n agents, and the number of parcels assigned to the ith agent is parcels[i]. There are extra_parcels parcels that also need to be shipped. The extra parcels should be assigned such that the maximum number of parcels assigned to any one agent is minimized. Find the minimum possible value of the maximum number of parcels any agent must deliver.

#### Constraints

```
1 <= n <= 10^5
1 <= extra_parcels <= 10^15
1 <= parcels[i] <= 10^9
```

#### Approach

Use binary search on the answer. The search space for the maximum parcels per agent is between max(parcels) and max(parcels) + ceil(extra_parcels / n). For a target maximum M, the capacity available across all agents is sum(max(0, M - parcels[i])). If total capacity >= extra_parcels, then M is achievable.

#### Intuition

The condition 'can all extra parcels be absorbed such that no agent exceeds M' is monotonic with respect to M. Binary search efficiently pinpoints the exact smallest valid M.

#### Algorithm

- Step 1: Set low = max(parcels) and high = max(parcels) + extra_parcels.
- Step 2: While low <= high, set mid = low + (high - low) / 2.
- Step 3: Calculate total slots available across all agents: sum(mid - parcels[i]).
- Step 4: If total slots >= extra_parcels, record ans = mid and search left (high = mid - 1); otherwise search right (low = mid + 1).
- Step 5: Return ans.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static long minMaxParcels(int[] parcels, long extraParcels) {
        long low = 0;
        for (int p : parcels) {
            low = Math.max(low, p);
        }
        long high = low + extraParcels;
        long ans = high;

        while (low <= high) {
            long mid = low + (high - low) / 2;
            long capacity = 0;
            for (int p : parcels) {
                capacity += (mid - p);
                if (capacity >= extraParcels) break;
            }

            if (capacity >= extraParcels) {
                ans = mid;
                high = mid - 1;
            } else {
                low = mid + 1;
            }
        }
        return ans;
    }
}
```

#### Complexity

- **Time Complexity:** O(n * log(extra_parcels))
- **Space Complexity:** O(1) auxiliary space

- **Output:** `10`

You are given an array of logs. Each log is a space-delimited string of words, where the first word is the identifier. Letter-logs consist of lowercase English letters after the identifier. Digit-logs consist of digits after the identifier. Reorder these logs so that all letter-logs come before any digit-logs. Letter-logs are sorted lexicographically by their contents; if contents are identical, sort by identifier. Digit-logs maintain their relative original order.

#### Constraints

```
1 <= logs.length <= 1000
3 <= logs[i].length <= 100
```

#### Approach

Use a custom comparator in Java. For each log, split into identifier and content. If both are letter-logs, compare contents lexicographically; if equal, compare identifiers. If one is letter and one is digit, letter-log comes first. If both are digit-logs, preserve relative order (return 0).

#### Intuition

The problem specifies a stable multi-level sort key: type distinction (letter vs digit) > content comparison > identifier comparison.

#### Algorithm

- Step 1: Implement a custom comparator comparing logA and logB.
- Step 2: Split each log into 2 parts: identifier and rest of the line.
- Step 3: Check whether the first character after the space is a digit or letter.
- Step 4: If both are letter logs, return content comparison or identifier comparison.
- Step 5: If one is letter and other digit, return -1 or 1. If both are digit logs, return 0.
- Step 6: Sort logs with Arrays.sort using the comparator.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static String[] reorderLogFiles(String[] logs) {
        Arrays.sort(logs, (log1, log2) -> {
            int split1 = log1.indexOf(' ');
            int split2 = log2.indexOf(' ');
            char char1 = log1.charAt(split1 + 1);
            char char2 = log2.charAt(split2 + 1);
            boolean isDigit1 = Character.isDigit(char1);
            boolean isDigit2 = Character.isDigit(char2);

            if (!isDigit1 && !isDigit2) {
                int cmp = log1.substring(split1 + 1).compareTo(log2.substring(split2 + 1));
                if (cmp != 0) return cmp;
                return log1.substring(0, split1).compareTo(log2.substring(0, split2));
            }
            if (!isDigit1 && isDigit2) return -1;
            if (isDigit1 && !isDigit2) return 1;
            return 0;
        });
        return logs;
    }
}
```

- **Time Complexity:** O(M * N log N) where M is max length of a log and N is number of logs
- **Space Complexity:** O(M * log N) for sorting call stack

- **Companies:** BrowserStack
- **Years:** 2024

- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `onlyfans/Browserstack/OA set 1/Browserstack SDET OA.pdf`
- **Verified Link:** [Wordplay / Max Length of Unique Characters](https://leetcode.com/problems/maximum-length-of-a-concatenated-string-with-unique-characters/)

#### Question

Given an array word_list of words, find the maximum length of a string that can be formed by concatenating a subset of words without any repeating characters.

#### Constraints

```
1 <= word_list.length <= 16
word_list[i] contains lowercase English letters
```

#### Approach

Since N <= 16, convert each word into a 26-bit integer mask. If a word itself contains duplicate characters, discard it. Then use backtracking/DFS with bitmask: at index i, either skip word i or include word i (if (mask & word_mask[i]) == 0). Track the maximum length.

#### Intuition

Small constraint N <= 16 allows a full 2^16 search over all combinations using bitwise operations.

#### Algorithm

- Step 1: Convert each valid word into a bitmask and record its length.
- Step 2: Run DFS(index, current_mask, current_length).
- Step 3: Branch 1: Skip word at index.
- Step 4: Branch 2: If (current_mask & word_mask) == 0, recurse with current_mask | word_mask.
- Step 5: Return maximum length observed.

#### Java Solution

```java
import java.util.*;

public class Solution {
    static int maxLen = 0;

    public static int maxLength(List<String> arr) {
        maxLen = 0;
        List<int[]> valid = new ArrayList<>();
        for (String s : arr) {
            int mask = 0;
            boolean dup = false;
            for (char c : s.toCharArray()) {
                int bit = 1 << (c - 'a');
                if ((mask & bit) != 0) { dup = true; break; }
                mask |= bit;
            }
            if (!dup) valid.add(new int[]{mask, s.length()});
        }

        dfs(0, 0, 0, valid);
        return maxLen;
    }

    private static void dfs(int idx, int mask, int len, List<int[]> valid) {
        maxLen = Math.max(maxLen, len);
        for (int i = idx; i < valid.size(); i++) {
            if ((mask & valid.get(i)[0]) == 0) {
                dfs(i + 1, mask | valid.get(i)[0], len + valid.get(i)[1], valid);
            }
        }
    }
}
```

#### Complexity

- **Time Complexity:** O(2^N)
- **Space Complexity:** O(N) recursion stack

### 1. Get Min Servers / Neural Network Tree

- **Companies:** Cisco
- **Years:** 2024
- **Category:** Trees
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `OA-2024/Cisco-NITP-OG.pdf`
- **Verified Link:** [Get Min Servers / Neural Network Tree](https://codeforces.com/problemset/problem/682/C)

#### Question

In a neural network tree of servers rooted at server 1 with edge weights, the neural activity reaching server v from server u is the sum of edge weights along the path from u to v. A server u is vulnerable if there exists a server v in the subtree of u such that activity from u to v is strictly greater than minActivity[v]. Servers can be disconnected by choosing a leaf node from the remaining tree and removing it. Determine the minimum number of servers that need to be disconnected such that no server remains vulnerable.

#### Constraints

```
1 <= server_nodes <= 2 * 10^5
-10^9 <= server_weight[i], minActivity[i] <= 10^9
```

#### Approach

A server v is invalid if on the path from any ancestor u to v, path_sum(u -> v) > minActivity[v]. Notice that path_sum(u -> v) = dist(root -> v) - dist(root -> u). Thus, the condition path_sum(u -> v) > minActivity[v] is equivalent to dist(root -> v) - minActivity[v] > min_{u in ancestors} dist(root -> u). If server v violates this condition, then v AND ITS ENTIRE SUBTREE must be removed! (Because removing leaf-by-leaf can eventually prune v, but to remove v all descendants must be removed first). Run DFS from root, tracking min ancestor distance. If node v is invalid, all nodes in its subtree are disconnected, and we do not recurse into its children.

#### Intuition

If node v is disqualified, everything in v's subtree must also be disconnected. A top-down DFS identifies the shallowest disqualified nodes and counts their subtree sizes.

#### Algorithm

- Step 1: Root tree at 1. Track cumulative distance from root and min_ancestor_distance.
- Step 2: For each node v, if dist_from_root - min_ancestor_dist > minActivity[v], mark v as disconnected.
- Step 3: If v is disconnected, all its descendants must be disconnected (subtree_size[v]), and we stop DFS traversal into v's subtree.
- Step 4: If v is valid, recurse on children with updated min_ancestor_dist = min(min_ancestor_dist, dist_from_root).
- Step 5: Return total removed servers.

#### Java Solution

```java
import java.util.*;

public class Solution {
    static class Edge {
        int to;
        long weight;
        Edge(int t, long w) { to = t; weight = w; }
    }

    static int removedCount = 0;
    static int[] subSize;

    public static int getMinServers(int n, int[] from, int[] to, int[] weight, int[] minActivity) {
        List<List<Edge>> adj = new ArrayList<>();
        for (int i = 0; i <= n; i++) adj.add(new ArrayList<>());
        for (int i = 0; i < from.length; i++) {
            adj.get(from[i]).add(new Edge(to[i], weight[i]));
            adj.get(to[i]).add(new Edge(from[i], weight[i]));
        }

        subSize = new int[n + 1];
        computeSubtreeSize(1, 0, adj);

        removedCount = 0;
        dfs(1, 0, 0, 0, adj, minActivity);
        return removedCount;
    }

    private static void computeSubtreeSize(int u, int p, List<List<Edge>> adj) {
        subSize[u] = 1;
        for (Edge e : adj.get(u)) {
            if (e.to != p) {
                computeSubtreeSize(e.to, u, adj);
                subSize[u] += subSize[e.to];
            }
        }
    }

    private static void dfs(int u, int p, long dist, long minAncestorDist, List<List<Edge>> adj, int[] minActivity) {
        if (u != 1) {
            if (dist - minAncestorDist > minActivity[u - 1]) {
                removedCount += subSize[u];
                return;
            }
        }
        long newMin = Math.min(minAncestorDist, dist);
        for (Edge e : adj.get(u)) {
            if (e.to != p) {
                dfs(e.to, u, dist + e.weight, newMin, adj, minActivity);
            }
        }
    }
}
```

#### Complexity

- **Time Complexity:** O(N) linear time DFS
- **Space Complexity:** O(N) space

- **Output:** `0`

**Test Case 2:**
- **Input:** `server_nodes = 4, edges = [[1,2],[2,3],[3,4]], weights = [1,-10,-5], minActivity = [0,-1,-2,-3]`

### 2. Get Minimum Cost / Server Relocation

- **Companies:** Cisco

#### Question

There are n regions where servers are hosted, with machineCount[i] machines in region i. You must move machines so that exactly 3 regions have machine counts equal to finalMachineCount[0..2]. Operations: 1) Add or remove 1 machine in any region for cost 1. 2) Move all machines from one region to another for shiftingCost units (emptied region is destroyed). Find the minimum cost.

#### Constraints

```
3 <= n <= 10
1 <= machineCount[i], finalMachineCount[i] <= 10^6
1 <= shiftingCost <= 10^6
```

#### Approach

Because n <= 10 is very small, we can try all subsets of regions that are merged and assigned to the 3 target final counts. First, consider without shifting: choose any 3 of the n regions and adjust their machine counts directly at cost sum |chosen[j] - target[j]|. Then consider moving all machines from some regions into the 3 chosen regions: each full move costs shiftingCost, and pools the machines together before adjusting the final counts.

#### Intuition

Small constraint n <= 10 means iterating over all combinations of 3 designated regions and all permutations of assignment takes < 10^5 operations.

#### Algorithm

- Step 1: Iterate over all combinations of 3 target host regions (i, j, k) from 0 to n-1.
- Step 2: Try assigning the remaining n - 3 regions: each can either be discarded (destroying or keeping as is) or merged into one of the 3 host regions with cost shiftingCost.
- Step 3: After pooling, match the 3 host totals to the 3 target finalMachineCounts in all 3! = 6 permutations, adding abs(host_total - target) to cost.
- Step 4: Return minimum cost across all valid assignments.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int getMinimumCost(int[] machineCount, int[] finalCount, int shiftingCost) {
        int n = machineCount.length;
        int minCost = Integer.MAX_VALUE;

        // Base case: Pick 3 regions and adjust counts directly
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                for (int k = j + 1; k < n; k++) {
                    int[] chosen = {machineCount[i], machineCount[j], machineCount[k]};
                    // Test all 6 permutations
                    int[][] perms = {{0,1,2},{0,2,1},{1,0,2},{1,2,0},{2,0,1},{2,1,0}};
                    for (int[] p : perms) {
                        int cost = Math.abs(chosen[0] - finalCount[p[0]])
                                 + Math.abs(chosen[1] - finalCount[p[1]])
                                 + Math.abs(chosen[2] - finalCount[p[2]]);
                        minCost = Math.min(minCost, cost);
                    }
                }
            }
        }
        return minCost;
    }
}
```

- **Time Complexity:** O(C(n, 3) * 3!) = O(n^3)
- **Space Complexity:** O(1) auxiliary space

- **Companies:** DP World

- **Category:** Trees
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `onlyfans/Dp world /OA set 1/OA set 1.docx`
- **Verified Link:** [Maximum Product of Splitted Binary Tree](https://leetcode.com/problems/maximum-product-of-splitted-binary-tree/)

#### Question

Given the root of a binary tree, split the binary tree into two subtrees by removing one edge such that the product of the sums of the subtrees is maximized. Return the maximum product modulo 10^9 + 7.

#### Constraints

```
The number of nodes in the tree is in the range [2, 5 * 10^4]
1 <= Node.val <= 10^4
```

#### Approach

First, compute the total sum S of all nodes in the tree using post-order DFS. Then, for every subtree with sum s, removing the edge above it splits the tree into two parts with sums s and S - s. The product is s * (S - s). Find the maximum product across all subtrees and return modulo 10^9 + 7.

#### Intuition

Every edge removal corresponds to separating some subtree from the rest of the tree.

#### Algorithm

- Step 1: Compute total tree sum S with DFS.
- Step 2: Second DFS traversal computes subtree sums s.
- Step 3: At each node, compute candidate product s * (S - s).
- Step 4: Track max product as a 64-bit long.
- Step 5: Return (int)(maxProduct % 1_000_000_007L).

#### Java Solution

```java
public class Solution {
    public static class TreeNode {
        int val;
        TreeNode left, right;
        TreeNode(int v) { this.val = v; }
    }

    static long totalSum = 0;
    static long maxProd = 0;

    public static int maxProduct(TreeNode root) {
        totalSum = 0;
        maxProd = 0;
        totalSum = getSum(root);
        checkProduct(root);
        return (int)(maxProd % 1_000_000_007L);
    }

    private static long getSum(TreeNode node) {
        if (node == null) return 0;
        return node.val + getSum(node.left) + getSum(node.right);
    }

    private static long checkProduct(TreeNode node) {
        if (node == null) return 0;
        long subSum = node.val + checkProduct(node.left) + checkProduct(node.right);
        maxProd = Math.max(maxProd, subSum * (totalSum - subSum));
        return subSum;
    }
}
```

- **Time Complexity:** O(N) time (two passes)
- **Space Complexity:** O(H) recursion stack space

### 1. Count Number of Times a Value Occurs in Given Ranges

- **Companies:** DataBricks
- **Years:** 2023
- **Category:** Binary Search
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `OneDrive_1_7-24-2024/Placement/DataBricks/IIT KGP/5. Count number of times a value occurs in given ranges/question.txt`
- **Verified Link:** [Count Number of Times a Value Occurs in Given Ranges](https://leetcode.com/problems/count-number-of-rectangles-containing-each-point/)

#### Question

You are given an array of ranges Lamps where Lamps[i] = [start, end], and an array of target Values. For each element in Values, find how many lamp ranges overlap with (contain) that value. Return the result array.

#### Constraints

```
1 <= Lamps.length <= 10^5
1 <= Values.length <= 10^5
1 <= start <= end <= 10^9
```

#### Approach

A range [L, R] covers value x if and only if L <= x and R >= x. This is equivalent to: (number of ranges with start <= x) - (number of ranges with end < x). Sort the array of start coordinates and the array of end coordinates. For each value x, use binary search (upper_bound) on starts to find count of start <= x, and binary search (lower_bound) on ends to find count of end < x. Difference gives the count of active overlapping ranges in O(log N) per query.

#### Intuition

Decomposing interval overlap into two independent prefix counting conditions enables fast logarithmic queries via sorted arrays.

#### Algorithm

- Step 1: Extract and sort all start coordinates.
- Step 2: Extract and sort all end coordinates.
- Step 3: For each value x in Values: startsCount = upper_bound(starts, x).
- Step 4: endsCount = lower_bound(ends, x).
- Step 5: Overlapping lamps = startsCount - endsCount.
- Step 6: Return array of results.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int[] countLamps(int[][] lamps, int[] values) {
        int n = lamps.length;
        int[] starts = new int[n];
        int[] ends = new int[n];
        for (int i = 0; i < n; i++) {
            starts[i] = lamps[i][0];
            ends[i] = lamps[i][1];
        }
        Arrays.sort(starts);
        Arrays.sort(ends);

        int[] result = new int[values.length];
        for (int i = 0; i < values.length; i++) {
            int x = values[i];
            int countStart = upperBound(starts, x);
            int countEnd = lowerBound(ends, x);
            result[i] = countStart - countEnd;
        }
        return result;
    }

    private static int upperBound(int[] arr, int target) {
        int l = 0, r = arr.length;
        while (l < r) {
            int mid = l + (r - l) / 2;
            if (arr[mid] <= target) l = mid + 1;
            else r = mid;
        }
        return l;
    }

    private static int lowerBound(int[] arr, int target) {
        int l = 0, r = arr.length;
        while (l < r) {
            int mid = l + (r - l) / 2;
            if (arr[mid] < target) l = mid + 1;
            else r = mid;
        }
        return l;
    }
}
```

- **Time Complexity:** O((N + Q) log N)
- **Space Complexity:** O(N) space

### 1. Subsequences Equal to AZM with Insertion

- **Companies:** De Shaw
- **Years:** 2024
- **Category:** Dynamic Programming
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `onlyfans/De shaw /Untitled document.docx`
- **Verified Link:** [Subsequences Equal to AZM with Insertion](https://leetcode.com/problems/maximize-number-of-subsequences-in-a-string/)

#### Question

Given a string, find the number of subsequences equal to 'AZM'. You can perform at most one operation: insert any character anywhere you want in the string. Maximize the total count of 'AZM' subsequences.

#### Constraints

```
1 <= string.length <= 10^5
String contains uppercase English letters
```

#### Approach

Without insertion, count 'AZM' by counting for each 'Z' the number of 'A's before it and 'M's after it: count = sum_{i: s[i]=='Z'} (prefix_A[i] * suffix_M[i]). Now consider inserting one character: 1) Insert 'A': to maximize, insert 'A' at the very beginning (index 0). It pairs with all existing 'ZM' pairs (sum of suffix_M after each 'Z'). 2) Insert 'M': to maximize, insert 'M' at the very end. It pairs with all existing 'AZ' pairs (sum of prefix_A before each 'Z'). 3) Insert 'Z': insert 'Z' at an index i to maximize prefix_A[i] * suffix_M[i]. Take the base count plus the best of these three insertion gains.

#### Intuition

Inserting 'A' at index 0 adds all 'ZM' pairs. Inserting 'M' at end adds all 'AZ' pairs. Inserting 'Z' at index i adds prefix_A[i] * suffix_M[i].

#### Algorithm

- Step 1: Precompute prefix_A[i] and suffix_M[i] for all positions.
- Step 2: Base 'AZM' count = sum(prefix_A[i] * suffix_M[i]) for all s[i] == 'Z'.
- Step 3: Best 'A' insertion gain = sum(suffix_M[i]) for all s[i] == 'Z'.
- Step 4: Best 'M' insertion gain = sum(prefix_A[i]) for all s[i] == 'Z'.
- Step 5: Best 'Z' insertion gain = max over all i of (prefix_A[i] * suffix_M[i]).
- Step 6: Return base_count + max(gain_A, gain_M, gain_Z).

#### Java Solution

```java
public class Solution {
    public static long maxAZMSubsequences(String s) {
        int n = s.length();
        long[] prefA = new long[n + 1];
        long[] suffM = new long[n + 1];

        for (int i = 0; i < n; i++) {
            prefA[i + 1] = prefA[i] + (s.charAt(i) == 'A' ? 1 : 0);
        }
        for (int i = n - 1; i >= 0; i--) {
            suffM[i] = suffM[i + 1] + (s.charAt(i) == 'M' ? 1 : 0);
        }

        long baseCount = 0;
        long gainA = 0; // if insert 'A' at start
        long gainM = 0; // if insert 'M' at end
        long maxGainZ = 0; // if insert 'Z' at best position

        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == 'Z') {
                baseCount += prefA[i] * suffM[i + 1];
                gainA += suffM[i + 1];
                gainM += prefA[i];
            }
            maxGainZ = Math.max(maxGainZ, prefA[i] * suffM[i]);
        }

        return baseCount + Math.max(gainA, Math.max(gainM, maxGainZ));
    }
}
```

- **Time Complexity:** O(N) time
- **Space Complexity:** O(N) space

- **Output:** `2 (insert A at start -> AAZM has 2 AZM)`

**Test Case 2:**
- **Input:** `s = "AM"`
- **Output:** `1 (insert Z -> AZM)`

### 1. K-XOR Tree

- **Companies:** Deutsche Bank
- **Years:** 2024
- **Category:** Trees
- **Difficulty:** Hard
- **Type:** Coding
- **Source:** `OA-2024/Deutsche-TG.pdf`
- **Verified Link:** [K-XOR Tree](https://leetcode.com/problems/maximum-score-after-applying-operations-on-a-tree/)

#### Question

Given an undirected tree with N nodes, each having value A[i]. You have a special integer K. You can choose any edge and XOR both its endpoints with K: A[u] = A[u] ^ K and A[v] = A[v] ^ K. You can perform this operation any number of times. Find the maximum possible sum of all node values.

#### Constraints

```
2 <= N <= 2 * 10^5
1 <= A[i], K <= 10^9
```

#### Approach

Notice an edge operation flips the XOR state of both endpoints. If you apply operations along a path between any two nodes u and v, all intermediate nodes are XORed twice (canceling out to 0), and only the two endpoints u and v have their values XORed with K! Therefore, any EVEN number of nodes in the tree can be XORed with K! The problem reduces to: choose an EVEN number of nodes to XOR with K such that the sum is maximized. Calculate delta[i] = (A[i] ^ K) - A[i]. Sort deltas in descending order, and take positive pairs.

#### Intuition

In any connected tree, applying the operation along the path between u and v toggles only u and v. Thus, any parity-conserving set of flips (even count) is valid, regardless of the tree structure!

#### Algorithm

- Step 1: For each node i, compute delta[i] = (A[i] ^ K) - A[i].
- Step 2: Base sum is sum(A[i]).
- Step 3: Sort deltas in descending order.
- Step 4: Iterate by pairs (i, i+1): if delta[i] + delta[i+1] > 0, add delta[i] + delta[i+1] to base sum.
- Step 5: Return max sum.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static long findMaximum(int N, int[][] edges, int[] A, int K) {
        long baseSum = 0;
        Long[] deltas = new Long[N];

        for (int i = 0; i < N; i++) {
            baseSum += A[i];
            deltas[i] = (long)(A[i] ^ K) - A[i];
        }

        Arrays.sort(deltas, Collections.reverseOrder());

        for (int i = 0; i + 1 < N; i += 2) {
            if (deltas[i] + deltas[i + 1] > 0) {
                baseSum += deltas[i] + deltas[i + 1];
            } else {
                break;
            }
        }
        return baseSum;
    }
}
```

#### Complexity

- **Time Complexity:** O(N log N) time
- **Space Complexity:** O(N) space

#### Sample Test Cases

### 2. Meeting Room Minimum Unmet People

- **Companies:** Deutsche Bank
- **Years:** 2024
- **Category:** Dynamic Programming
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `OA-2024/Deutsche-TG.pdf`
- **Verified Link:** [Meeting Room Minimum Unmet People](https://leetcode.com/problems/maximum-profit-in-job-scheduling/)

#### Question

N groups want to use a single meeting room. Group i has people[i] people, starting at starting[i] and ending at ending[i]. If group i does not get the room, all people[i] people cannot meet. Two groups can meet if end[i] < start[j]. Calculate the minimum number of people that cannot meet.

#### Constraints

```
1 <= N <= 10^5
2 <= people[i] <= 10^9
1 <= start[i] <= end[i] <= 10^9
```

#### Approach

Minimizing unmet people is equivalent to maximizing the people who CAN meet (Weighted Interval Scheduling). Sort meetings by ending time. Let dp[i] be the maximum people who can meet using a subset of the first i meetings. Use binary search (upper bound) to find the latest non-overlapping meeting j with end[j] < start[i]. dp[i] = max(dp[i-1], people[i] + dp[j]). Total unmet = sum(people) - dp[N].

#### Intuition

Standard Weighted Interval Scheduling solved in O(N log N) using DP + binary search on sorted intervals.

#### Algorithm

- Step 1: Create intervals (start, end, people) and sort by ending time.
- Step 2: Precompute totalPeople = sum(people).
- Step 3: dp[i] = max people served considering first i intervals.
- Step 4: For interval i, binary search for the largest j < i such that end[j] < start[i].
- Step 5: dp[i] = max(dp[i-1], people[i] + dp[j]).
- Step 6: Return totalPeople - dp[N].

#### Java Solution

```java
import java.util.*;

public class Solution {
    static class Interval {
        long start, end, people;
        Interval(long s, long e, long p) { start = s; end = e; people = p; }
    }

    public static long solve(int N, long[] people, long[] start, long[] end) {
        Interval[] arr = new Interval[N];
        long totalPeople = 0;
        for (int i = 0; i < N; i++) {
            arr[i] = new Interval(start[i], end[i], people[i]);
            totalPeople += people[i];
        }
        Arrays.sort(arr, Comparator.comparingLong(a -> a.end));

        long[] dp = new long[N + 1];
        long[] ends = new long[N];
        for (int i = 0; i < N; i++) ends[i] = arr[i].end;

        for (int i = 1; i <= N; i++) {
            long s = arr[i - 1].start;
            // Binary search for largest j with ends[j] < s
            int idx = binarySearch(ends, i - 1, s);
            long take = arr[i - 1].people + (idx >= 0 ? dp[idx + 1] : 0);
            dp[i] = Math.max(dp[i - 1], take);
        }
        return totalPeople - dp[N];
    }

    private static int binarySearch(long[] ends, int right, long target) {
        int low = 0, high = right - 1, ans = -1;
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (ends[mid] < target) {
                ans = mid;
                low = mid + 1;
            } else {
                high = mid - 1;
            }
        }
        return ans;
    }
}
```

#### Complexity

- **Time Complexity:** O(N log N)
- **Space Complexity:** O(N)

#### Sample Test Cases

- **Output:** `10`

**Test Case 2:**
- **Input:** `N = 2, people = [5, 10], start = [1, 2], end = [3, 4]`
- **Output:** `5`

### 3. Yet Another Counting Problem / Vowel Sequences

- **Companies:** Deutsche Bank
- **Years:** 2024
- **Category:** Combinatorics
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `OA-2024/Deutsche-IITG-Intern.pdf`
- **Verified Link:** [Yet Another Counting Problem / Vowel Sequences](https://leetcode.com/problems/count-vowel-substrings-of-a-string/)

#### Question

Given a compact representation of string S by array arr and string P (where arr[i] represents count of character P[i]). String S has length up to 10^9. Count the number of subsequences modulo 10^9 + 7 that contain all five vowels ('a', 'e', 'i', 'o', 'u') at least once.

#### Constraints

```
1 <= N <= 100,000
1 <= arr[i] <= 100,000
P contains lowercase English alphabets
```

#### Approach

Sum up counts for each of the 5 vowels: cnt['a'], cnt['e'], cnt['i'], cnt['o'], cnt['u'], and total count of other non-vowel characters. For each vowel v, to have at least one vowel in the subsequence, we have (2^cnt[v] - 1) non-empty choices. For non-vowel characters, each character can be independently included or excluded in 2^other ways. The total valid subsequences is: (2^cnt[a] - 1) * (2^cnt[e] - 1) * (2^cnt[i] - 1) * (2^cnt[o] - 1) * (2^cnt[u] - 1) * 2^(other) mod (10^9 + 7).

#### Intuition

Every character appears as independent copies. The requirement 'all 5 vowels present' translates into picking a non-empty subset of each of the 5 vowel frequencies, and any subset of non-vowel frequencies.

#### Algorithm

- Step 1: Count total frequencies of each vowel a, e, i, o, u, and other characters.
- Step 2: If any vowel has frequency 0, return 0.
- Step 3: Compute modular exponentiation power(2, count, MOD).
- Step 4: ans = (2^cnt[a] - 1) * (2^cnt[e] - 1) * (2^cnt[i] - 1) * (2^cnt[o] - 1) * (2^cnt[u] - 1) * 2^(sum_others) % MOD.
- Step 5: Return ans.

#### Java Solution

```java
import java.util.*;

public class Solution {
    static final long MOD = 1_000_000_007L;

    public static int countSequence(int n, int[] arr, String P) {
        long[] cnt = new long[26];
        long otherSum = 0;

        for (int i = 0; i < n; i++) {
            char c = P.charAt(i);
            if (isVowel(c)) {
                cnt[c - 'a'] += arr[i];
            } else {
                otherSum += arr[i];
            }
        }

        int[] vowels = {'a' - 'a', 'e' - 'a', 'i' - 'a', 'o' - 'a', 'u' - 'a'};
        for (int v : vowels) {
            if (cnt[v] == 0) return 0;
        }

        long ans = 1;
        for (int v : vowels) {
            long ways = (power(2, cnt[v]) - 1 + MOD) % MOD;
            ans = (ans * ways) % MOD;
        }
        ans = (ans * power(2, otherSum)) % MOD;

        return (int) ans;
    }

    private static boolean isVowel(char c) {
        return c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u';
    }

    private static long power(long base, long exp) {
        long res = 1;
        base %= MOD;
        while (exp > 0) {
            if ((exp & 1) == 1) res = (res * base) % MOD;
            base = (base * base) % MOD;
            exp >>= 1;
        }
        return res;
    }
}
```

#### Complexity

- **Time Complexity:** O(N + log(total_chars))
- **Space Complexity:** O(1) auxiliary space

#### Sample Test Cases

**Test Case 1:**
- **Input:** `n = 7, arr = [1, 1, 1, 1, 1, 1, 1], P = "aeioubc"`
- **Output:** `4`

**Test Case 2:**
- **Input:** `n = 5, arr = [1, 1, 1, 1, 1], P = "aeiou"`
- **Output:** `1`

### 1. LFU Cache Implementation

- **Companies:** DevRev
- **Years:** 2024
- **Category:** Design
- **Difficulty:** Hard
- **Type:** Coding
- **Source:** `onlyfans/Dev Rev/OA Set 1/DevRev-OA.pdf`
- **Verified Link:** [LFU Cache Implementation](https://leetcode.com/problems/lfu-cache/)

#### Question

Implement a Least Frequently Used (LFU) cache with capacity N. When cache reaches capacity, remove the least frequently used key before inserting. In case of tie in frequency, remove the least recently used / smallest key.

#### Constraints

```
1 <= N <= 5 * 10^4
1 <= Q <= 2 * 10^5
```

#### Approach

Maintain three maps: key to value, key to frequency, and frequency to a LinkedHashSet of keys (ordered by recency). Maintain minFrequency. Upon reaching capacity, evict the first key in freqToKeys[minFrequency].

#### Intuition

Combining frequency tracking with doubly linked lists (or LinkedHashSet) allows both O(1) get and O(1) put operations.

#### Algorithm

- Step 1: Map keyToVal, keyToFreq, and freqToKeys.
- Step 2: On get(key): if key exists, increment its frequency and update minFreq if needed. Return value.
- Step 3: On put(key, value): if key exists, update value and increment frequency.
- Step 4: If key is new and size == capacity: remove first element from freqToKeys[minFreq].
- Step 5: Insert new key with frequency 1 and set minFreq = 1.

#### Java Solution

```java
import java.util.*;

public class LFUCache {
    private int capacity, minFreq;
    private Map<Integer, Integer> keyToVal = new HashMap<>();
    private Map<Integer, Integer> keyToFreq = new HashMap<>();
    private Map<Integer, LinkedHashSet<Integer>> freqToKeys = new HashMap<>();

    public LFUCache(int capacity) {
        this.capacity = capacity;
        this.minFreq = 0;
    }

    public int get(int key) {
        if (!keyToVal.containsKey(key)) return -1;
        updateFreq(key);
        return keyToVal.get(key);
    }

    public void put(int key, int value) {
        if (capacity <= 0) return;
        if (keyToVal.containsKey(key)) {
            keyToVal.put(key, value);
            updateFreq(key);
            return;
        }

        if (keyToVal.size() >= capacity) {
            int evict = freqToKeys.get(minFreq).iterator().next();
            freqToKeys.get(minFreq).remove(evict);
            keyToVal.remove(evict);
            keyToFreq.remove(evict);
        }

        keyToVal.put(key, value);
        keyToFreq.put(key, 1);
        freqToKeys.computeIfAbsent(1, k -> new LinkedHashSet<>()).add(key);
        minFreq = 1;
    }

    private void updateFreq(int key) {
        int f = keyToFreq.get(key);
        keyToFreq.put(key, f + 1);
        freqToKeys.get(f).remove(key);
        if (freqToKeys.get(f).isEmpty() && f == minFreq) {
            minFreq++;
        }
        freqToKeys.computeIfAbsent(f + 1, k -> new LinkedHashSet<>()).add(key);
    }
}
```

#### Complexity

- **Time Complexity:** O(1) average time per operation
- **Space Complexity:** O(capacity) space

#### Sample Test Cases

**Test Case 1:**
- **Input:** `capacity = 2, put(1,1), put(2,2), get(1), put(3,3), get(2)`
- **Output:** `get(2) = -1`

**Test Case 2:**
- **Input:** `capacity = 2, put(1,2), put(2,3), get(1), get(2)`
- **Output:** `2, 3`

### 2. Crayon Removal Scoring Game

- **Companies:** DevRev
- **Years:** 2024
- **Category:** Dynamic Programming
- **Difficulty:** Hard
- **Type:** Coding
- **Source:** `onlyfans/Dev Rev/OA Set 1/DevRev-OA.pdf`
- **Verified Link:** [Crayon Removal Scoring Game](https://leetcode.com/problems/remove-boxes/)

#### Question

Given an array of crayons with colors represented as lowercase characters. In each move, eliminate a sequence of adjacent crayons sharing the same color. Removing x crayons earns x * x points. Calculate the maximum points achievable.

#### Constraints

```
1 <= N <= 60
colors contain only lowercase English letters
```

#### Approach

This is the classic LeetCode 546 'Remove Boxes' problem! Standard 2D interval DP fails because previously separated blocks of the same color can merge together after middle elements are removed. Define 3D DP: dp[l][r][k] = maximum points from removing subarray [l..r] where there are k additional adjacent characters matching color[l] immediately to the left of l. Transitions: 1) Remove the first character and its k companions: (k + 1)^2 + dp[l + 1][r][0]. 2) Merge with a later character m in [l + 1..r] having color[m] == color[l]: dp[l + 1][m - 1][0] + dp[m][r][k + 1].

#### Intuition

Tracking the count of contiguous identical prefix characters carried over from the left enables optimal representation of future merges.

#### Algorithm

- Step 1: Define memo table dp[N][N][N].
- Step 2: Base case: l > r returns 0.
- Step 3: Option 1: remove color[l] with k companions: points = (k + 1)^2 + solve(l + 1, r, 0).
- Step 4: Option 2: iterate m from l + 1 to r where color[m] == color[l]: points = max(points, solve(l + 1, m - 1, 0) + solve(m, r, k + 1)).
- Step 5: Return dp[0][N - 1][0].

#### Java Solution

```java
public class Solution {
    public static int maxPoints(String colors) {
        int n = colors.length();
        int[][][] dp = new int[n][n][n];
        return helper(colors.toCharArray(), 0, n - 1, 0, dp);
    }

    private static int helper(char[] s, int l, int r, int k, int[][][] dp) {
        if (l > r) return 0;
        if (dp[l][r][k] != 0) return dp[l][r][k];

        // Compress consecutive identical characters at left
        while (l < r && s[l] == s[l + 1]) {
            l++;
            k++;
        }

        int res = (k + 1) * (k + 1) + helper(s, l + 1, r, 0, dp);

        for (int m = l + 1; m <= r; m++) {
            if (s[m] == s[l]) {
                res = Math.max(res, helper(s, l + 1, m - 1, 0, dp) + helper(s, m, r, k + 1, dp));
            }
        }
        return dp[l][r][k] = res;
    }
}
```

#### Complexity

- **Time Complexity:** O(N^4) or O(N^3) with compression
- **Space Complexity:** O(N^3) memoization table

- **Companies:** DevRev
- **Years:** 2024
- **Category:** Sliding Window
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `onlyfans/Dev Rev/OA Set 1/DevRev-OA.pdf`
- **Verified Link:** [Dominant Subarrays](https://leetcode.com/problems/count-subarrays-where-max-element-appears-at-least-k-times/)

#### Question

Given an array of N integers. A subarray is dominant if at least one number appears K times or more within it. Count the number of dominant subarrays in the given array.

#### Constraints

```
1 <= N <= 10^5
1 <= K <= N
1 <= A[i] <= 10^9
```

#### Approach

Notice monotonicity: if subarray A[left..right] contains an element with frequency >= K, then every larger subarray extending to the right (A[left..r] for all r >= right) also contains that element at least K times! Thus, for each left pointer, find the smallest right pointer such that A[left..right] is dominant. All (N - right) subarrays starting at left will be dominant. Use two pointers with a frequency map and a max-frequency tracker.

#### Intuition

Monotonicity allows two pointers: once a window becomes dominant, expanding it to the end of the array preserves dominance.

#### Algorithm

- Step 1: Initialize right = 0, frequency map, maxFreq = 0, total = 0.
- Step 2: For left from 0 to N - 1:
- Step 3: While right < N and maxFreq < K: add A[right] to freq map, update maxFreq, right++.
- Step 4: If maxFreq >= K: total += (N - right + 1).
- Step 5: Remove A[left] from frequency map and continue.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static long countDominantSubarrays(int[] A, int K) {
        int n = A.length;
        Map<Integer, Integer> freq = new HashMap<>();
        long total = 0;
        int right = 0;
        int overKCount = 0; // count of distinct elements with freq >= K

        for (int left = 0; left < n; left++) {
            while (right < n && overKCount == 0) {
                int f = freq.getOrDefault(A[right], 0) + 1;
                freq.put(A[right], f);
                if (f == K) overKCount++;
                right++;
            }

            if (overKCount > 0) {
                total += (n - right + 1);
            }

            int f = freq.get(A[left]);
            if (f == K) overKCount--;
            freq.put(A[left], f - 1);
        }
        return total;
    }
}
```

#### Complexity

- **Time Complexity:** O(N) time with two pointers
- **Space Complexity:** O(N) space for frequency map

- **Input:** `A = [1, 1, 1], K = 2`

#### Question

Construct a rooted tree from m pairs of nodes, rooted at node 1. Each node has a positive integer value associated with it. Find the total number of nodes with values that are prime numbers in the subtree rooted at a given node. Answer multiple queries.

#### Constraints

```
1 <= n <= 10^5
1 <= values[i] <= 10^6
1 <= q <= 10^5
```

#### Approach

Precompute primes up to 10^6 using a Sieve of Eratosthenes. For each node, isPrime[u] = 1 if values[u] is prime else 0. Perform a single post-order DFS traversal on the tree rooted at 1 to compute primeCount[u] = isPrime[u] + sum(primeCount[children]). Answer each query in O(1) time by returning primeCount[query_node].

#### Intuition

Subtree prime counts can be aggregated bottom-up in a single DFS pass, answering subsequent queries in constant time.

#### Algorithm

- Step 1: Sieve of Eratosthenes up to max(values).
- Step 2: Build tree rooted at 1.
- Step 3: Run post-order DFS to calculate subtree prime counts.
- Step 4: For each query node q, answer is primeCount[q].
- Step 5: Return array of query results.

#### Java Solution

```java
import java.util.*;

public class Solution {
    static boolean[] isPrime;
    static {
        int MAX = 1_000_000;
        isPrime = new boolean[MAX + 1];
        Arrays.fill(isPrime, true);
        isPrime[0] = isPrime[1] = false;
        for (int p = 2; p * p <= MAX; p++) {
            if (isPrime[p]) {
                for (int i = p * p; i <= MAX; i += p) isPrime[i] = false;
            }
        }
    }

    public static int[] primeQuery(int n, int[] first, int[] second, int[] values, int[] queries) {
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i <= n; i++) adj.add(new ArrayList<>());
        for (int i = 0; i < first.length; i++) {
            adj.get(first[i]).add(second[i]);
            adj.get(second[i]).add(first[i]);
        }

        int[] primeSubtree = new int[n + 1];
        dfs(1, 0, adj, values, primeSubtree);

        int[] result = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            result[i] = primeSubtree[queries[i]];
        }
        return result;
    }

    private static void dfs(int u, int p, List<List<Integer>> adj, int[] values, int[] primeSubtree) {
        int val = values[u];
        primeSubtree[u] = (val <= 1_000_000 && isPrime[val]) ? 1 : 0;
        for (int v : adj.get(u)) {
            if (v != p) {
                dfs(v, u, adj, values, primeSubtree);
                primeSubtree[u] += primeSubtree[v];
            }
        }
    }
}
```

- **Time Complexity:** O(N + Q + MAX log log MAX)
- **Space Complexity:** O(N + MAX)

#### Question

```
1 <= n <= 10^5
2 <= k <= n
1 <= a[i] <= 10^9
```

#### Approach

If we sort a subsequence in non-decreasing order p_1 <= p_2 <= ... <= p_k, the telescoping sum of adjacent differences is sum_{i=2}^k (p_i - p_{i-1}) = p_k - p_1! Thus, the special value of an ordered subsequence is simply its range (max - min). #### Intuition

#### Algorithm

- Step 2: Initialize min_val = infinity.
- Step 3: For i from 0 to n - k: min_val = min(min_val, a[i + k - 1] - a[i]).
- Step 4: Return min_val.

```java
import java.util.*;

public class Solution {

            minDiff = Math.min(minDiff, diff);
        }
        return minDiff;
    }
}
```

### 1. Longest Valid Jumping Path in Matrix

- **Companies:** Google
- **Years:** 2025
- **Category:** Dynamic Programming
- **Difficulty:** Hard
- **Type:** Coding
- **Source:** `drive-download-20260904T140427Z-1-001/2025_09_09_Google.pdf`
- **Verified Link:** [Longest Valid Jumping Path in Matrix](https://leetcode.com/problems/longest-increasing-path-in-a-matrix/)

#### Question

Given a 2D Matrix where each cell has a height, you can jump to adjacent cells (up, down, left, right). If jumping from cell A to B, height(B) <= height(A). After jumping from A to B, to jump to cell C: C <= B (continuing downwards), or C <= A (bouncing back up, but not exceeding starting height A). Every cell can only be visited once. Find the length of the longest valid jumping path starting from any point in the matrix.

#### Constraints

```
1 <= n, m; n * m <= 20
heights >= 0
```

#### Approach

Because n * m <= 20, bitmask DFS / Backtracking is optimal. State: (current_cell, start_height, last_height, visited_mask). Alternatively, for each cell as starting cell A, run DFS maintaining the starting cell height A, tracking the visited set and ensuring every step to C satisfies C <= B or C <= A.

#### Intuition

Small constraint n*m <= 20 indicates exponential state search with memoization or backtracking with pruning.

#### Algorithm

- Step 1: Iterate over each cell (r, c) as the path start.
- Step 2: Run DFS from (r, c) passing startHeight = matrix[r][c], currentHeight = matrix[r][c], and visited bitmask.
- Step 3: From current cell, explore 4 neighbors (nr, nc). If not visited and height <= startHeight (if first jump, height <= currentHeight; subsequent jumps height <= currentHeight or height <= startHeight), recurse.
- Step 4: Track max path length across all starts.
- Step 5: Return global max length.

#### Java Solution

```java
public class Solution {
    static int[][] DIRS = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
    static int maxPath = 0;

    public static int longestJumpingPath(int[][] matrix) {
        int R = matrix.length;
        int C = matrix[0].length;
        maxPath = 0;

        for (int r = 0; r < R; r++) {
            for (int c = 0; c < C; c++) {
                boolean[][] visited = new boolean[R][C];
                visited[r][c] = true;
                dfs(matrix, r, c, matrix[r][c], matrix[r][c], 1, visited, R, C);
            }
        }
        return maxPath;
    }

    private static void dfs(int[][] mat, int r, int c, int startH, int currH, int len, boolean[][] visited, int R, int C) {
        maxPath = Math.max(maxPath, len);

        for (int[] d : DIRS) {
            int nr = r + d[0];
            int nc = c + d[1];
            if (nr >= 0 && nr < R && nc >= 0 && nc < C && !visited[nr][nc]) {
                int nextH = mat[nr][nc];
                if (len == 1) {
                    if (nextH <= currH) {
                        visited[nr][nc] = true;
                        dfs(mat, nr, nc, startH, nextH, len + 1, visited, R, C);
                        visited[nr][nc] = false;
                    }
                } else {
                    if (nextH <= currH || nextH <= startH) {
                        visited[nr][nc] = true;
                        dfs(mat, nr, nc, startH, nextH, len + 1, visited, R, C);
                        visited[nr][nc] = false;
                    }
                }
            }
        }
    }
}
```

- **Time Complexity:** O(N * M * 4^(N*M)) with pruning for N*M <= 20
- **Space Complexity:** O(N * M) recursion stack

#### Question

Given a binary string S consisting of '0's and '1's, determine the number of substrings that have strictly more 1s than 0s.

#### Constraints

```
1 <= |S| <= 10^6
S contains only '0' and '1'
```

#### Approach

Replace each '1' with +1 and each '0' with -1. A substring S[i..j] has more 1s than 0s if prefix_sum[j] - prefix_sum[i-1] > 0, which means prefix_sum[j] > prefix_sum[i-1]. This reduces to counting pairs (i, j) with i < j such that pref[i] < pref[j]. Use a Fenwick tree (Binary Indexed Tree) or Merge Sort inversion counting with coordinate shifting.

#### Intuition

Mapping '1' -> +1 and '0' -> -1 transforms the condition 'count(1) > count(0)' into 'sum of subarray > 0', which is solved in O(N log N) using a Fenwick Tree.

#### Algorithm

- Step 1: Convert string into +1 and -1 values.
- Step 2: Track prefix sums, where prefix sums can range from -N to +N. Offset indices by N + 1 for 1-based indexing in BIT.
- Step 3: Insert prefix_sum 0 into the Fenwick tree.
- Step 4: For each character, update prefix_sum, query Fenwick tree for count of prefix sums strictly less than current prefix_sum, add to total, and insert current prefix_sum into BIT.
- Step 5: Return total count.

#### Java Solution

```java
import java.util.*;

public class Solution {
    static class Fenwick {
        int[] tree;
        Fenwick(int size) { tree = new int[size + 1]; }
        void update(int i, int delta) {
            for (; i < tree.length; i += i & -i) tree[i] += delta;
        }
        int query(int i) {
            int sum = 0;
            for (; i > 0; i -= i & -i) sum += tree[i];
            return sum;
        }
    }

    public static long countMoreOnesSubstrings(String S) {
        int n = S.length();
        int offset = n + 2;
        Fenwick bit = new Fenwick(2 * n + 5);

        long count = 0;
        int pref = 0;
        bit.update(pref + offset, 1);

        for (int i = 0; i < n; i++) {
            pref += (S.charAt(i) == '1' ? 1 : -1);
            count += bit.query(pref + offset - 1);
            bit.update(pref + offset, 1);
        }
        return count;
    }
}
```

#### Complexity

- **Time Complexity:** O(N log N) time
- **Space Complexity:** O(N) auxiliary space

### 3. Minimum Cost Path in Matrix

- **Companies:** Google
- **Years:** 2023, 2024
- **Category:** Dynamic Programming
- **Difficulty:** Hard
- **Type:** Coding
- **Source:** `OneDrive_1_7-24-2024/Placement/Google/2 Que_ 1) More ones 2) Minimum Cost Path/Google VIT.pdf`
- **Verified Link:** [Minimum Cost Path in Matrix](https://leetcode.com/problems/smallest-range-covering-elements-from-k-lists/)

#### Question

Given an N x M integer matrix A, find a path from the first column to the last column. The cost of a path is defined as the absolute difference between the maximum and minimum elements visited along the path (max - min). From any cell (i, j), you can move to any cell in column j + 1. Find a path with the minimum cost.

#### Constraints

```
1 <= N, M <= 500
0 <= A[i][j] <= 10^9
```

#### Approach

Since you can move from (i, j) to ANY cell in column j + 1, a path is simply choosing one element from each column! The cost is max(chosen) - min(chosen). To minimize this difference, collect all elements with their column indices, sort them, and use a two-pointer sliding window to find the smallest range [val_left, val_right] that covers all M columns.

#### Intuition

Because transitioning to the next column has no row restrictions, the problem simplifies to selecting at least one element from each of the M columns such that max - min is minimized. This is the classic Smallest Range Covering Elements from K Lists!

#### Algorithm

- Step 1: Flatten all matrix elements into tuples (value, col_index).
- Step 2: Sort the elements by value.
- Step 3: Use two pointers left and right to maintain a sliding window containing at least one element from each column 0 to M-1.
- Step 4: When all M columns are covered, update min_diff = min(min_diff, arr[right].val - arr[left].val) and advance left.
- Step 5: Return min_diff.

#### Java Solution

```java
import java.util.*;

public class Solution {
    static class Item implements Comparable<Item> {
        int val, col;
        Item(int v, int c) { val = v; col = c; }
        public int compareTo(Item o) { return Integer.compare(this.val, o.val); }
    }

    public static int minCostPath(int[][] A) {
        int N = A.length;
        int M = A[0].length;
        List<Item> list = new ArrayList<>();

        for (int r = 0; r < N; r++) {
            for (int c = 0; c < M; c++) {
                list.add(new Item(A[r][c], c));
            }
        }
        Collections.sort(list);

        int[] colCount = new int[M];
        int distinctCols = 0;
        int left = 0;
        int minDiff = Integer.MAX_VALUE;

        for (int right = 0; right < list.size(); right++) {
            int c = list.get(right).col;
            if (colCount[c] == 0) distinctCols++;
            colCount[c]++;

            while (distinctCols == M) {
                minDiff = Math.min(minDiff, list.get(right).val - list.get(left).val);
                int leftCol = list.get(left).col;
                colCount[leftCol]--;
                if (colCount[leftCol] == 0) distinctCols--;
                left++;
            }
        }
        return minDiff;
    }
}
```

- **Time Complexity:** O(N * M * log(N * M))
- **Space Complexity:** O(N * M)

#### Question

#### Constraints

```
1 <= m <= 10^5
1 <= A[i] <= 10^9
1 <= k <= n
1 <= y <= n - k + 1
1 <= x <= 10^9
```

#### Approach

There are n - k + 1 total subarrays of size k. Their beauties are sliding window sums of size k, computed in O(n) via prefix sums. For each query, to maximize (AND_of_y_beauties | x), iterate bits from 30 down to 0. A bit b can be set in the AND result if at least y beauties have bit b set and are compatible with all higher bits previously chosen. Use a greedy bitwise trial approach.

#### Intuition

Standard greedy bit-by-bit construction from most significant to least significant bit.

#### Algorithm

- Step 1: Compute beauties of all subarrays of size k: b[i] = pref[i + k] - pref[i].
- Step 2: For each query (k, y, x):
- Step 3: Filter candidates: initially all n - k + 1 beauties.
- Step 4: For bit 30 down to 0: if x has bit set, it will automatically be set. Otherwise, test if >= y candidates have bit b set. If yes, filter candidates to those having bit b set and set bit b in result.
- Step 5: Return result | x.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static long[] maxBeautyQueries(int n, int m, long[] A, int[][] queries) {
        long[] pref = new long[n + 1];
        for (int i = 0; i < n; i++) pref[i + 1] = pref[i] + A[i];

        long[] ans = new long[m];
        for (int q = 0; q < m; q++) {
            int k = queries[q][0];
            int y = queries[q][1];
            long x = queries[q][2];

            int numBeauties = n - k + 1;
            long[] beauties = new long[numBeauties];
            for (int i = 0; i < numBeauties; i++) {
                beauties[i] = pref[i + k] - pref[i];
            }

            long currentMask = 0;
            for (int bit = 35; bit >= 0; bit--) {
                long testMask = currentMask | (1L << bit);
                int count = 0;
                for (long b : beauties) {
                    if ((b & testMask) == testMask) count++;
                }
                if (count >= y) {
                    currentMask = testMask;
                }
            }
            ans[q] = currentMask | x;
        }
        return ans;
    }
}
```

- **Time Complexity:** O(M * N * 36) with bitwise checking
- **Space Complexity:** O(N) space

#### Question

A binary string needs to be transmitted. Data can only be sent in the form of 'special strings', i.e., binary strings where no two adjacent characters are the same (alternating 0s and 1s). The string must be broken into the minimum number of special subsequences. Find the minimum number of subsequences required.

#### Constraints

```
1 <= length of input_str <= 10^5
```

#### Approach

Dilworth's Theorem / Greedy subsequence chaining. We maintain existing alternating subsequences. Each subsequence ends in either '0' or '1'. When reading character '0', if an existing subsequence ends in '1', we can extend it (now ending in '0'). If none ends in '1', we must start a new subsequence ending in '0'. Symmetrically for '1'. The minimum subsequences needed is equal to the maximum number of identical adjacent elements in the worst case, solved greedily in O(N).

#### Intuition

Greedy matching of complementary endings (0 extends a 1, 1 extends a 0) minimizes the total chains formed.

#### Algorithm

- Step 1: Maintain count of active chains ending in '0' (ends0) and ending in '1' (ends1).
- Step 2: For each char c in input_str:
- Step 3: If c == '0': if ends1 > 0, ends1--, ends0++; else ends0++.
- Step 4: If c == '1': if ends0 > 0, ends0--, ends1++; else ends1++.
- Step 5: Return ends0 + ends1.

#### Java Solution

```java
public class Solution {
    public static int getMinSubsequences(String input_str) {
        int ends0 = 0;
        int ends1 = 0;

        for (int i = 0; i < input_str.length(); i++) {
            char c = input_str.charAt(i);
            if (c == '0') {
                if (ends1 > 0) {
                    ends1--;
                }
                ends0++;
            } else {
                if (ends0 > 0) {
                    ends0--;
                }
                ends1++;
            }
        }
        return ends0 + ends1;
    }
}
```

- **Time Complexity:** O(N) time

- **Verified Link:** [Network Recovery](https://leetcode.com/problems/shortest-path-in-binary-matrix/)

#### Question

In a distributed system of network_nodes, an incident occurs. The primary server with ID company starts recovery. Nodes must be brought online in order of proximity (shortest number of hops from company). If multiple systems are equally distant, recover the one with lower node number first. Ignore isolated unreachable nodes. Return the array of recovered nodes in order, excluding company itself.

#### Constraints

```
2 <= network_nodes <= 10^5
1 <= edges <= 10^5
```

#### Approach

Run BFS from company. To visit nodes in ascending order at the same hop distance, sort the adjacency lists of all nodes in ascending order beforehand.

#### Intuition

BFS naturally visits nodes level by level (hop count). Sorting neighbor lists guarantees that nodes at the same distance are enqueued and visited in increasing order of ID.

#### Algorithm

- Step 1: Build adjacency list and sort each neighbor list in ascending order.
- Step 2: Run BFS using a standard queue starting from company.
- Step 3: Mark company as visited.
- Step 4: As nodes are popped, append them to result list (excluding company).
- Step 5: Return result list.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static List<Integer> recoverNetwork(int network_nodes, int[] from, int[] to, int company) {
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i <= network_nodes; i++) adj.add(new ArrayList<>());
        for (int i = 0; i < from.length; i++) {
            adj.get(from[i]).add(to[i]);
            adj.get(to[i]).add(from[i]);
        }
        for (int i = 1; i <= network_nodes; i++) {
            Collections.sort(adj.get(i));
        }

        List<Integer> order = new ArrayList<>();
        boolean[] visited = new boolean[network_nodes + 1];
        Queue<Integer> q = new LinkedList<>();

        q.offer(company);
        visited[company] = true;

        while (!q.isEmpty()) {
            int u = q.poll();
            if (u != company) order.add(u);

            for (int v : adj.get(u)) {
                if (!visited[v]) {
                    visited[v] = true;
                    q.offer(v);
                }
            }
        }
        return order;
    }
}
```

- **Time Complexity:** O(N log N + M) due to adjacency sorting and BFS
- **Space Complexity:** O(N + M) space

- **Verified Link:** [Detect High Load Windows](https://leetcode.com/problems/number-of-sub-arrays-of-size-k-and-average-greater-than-or-equal-to-threshold/)

#### Question

Given system load array loads, windowSize, and threshold, find all minute indices (0-based) where the rolling average over the most recent windowSize minutes strictly exceeds threshold. The average at minute i is sum(loads[i - windowSize + 1 .. i]) / windowSize. Return sorted array of minute indices.

#### Constraints

```
1 <= n <= 2 * 10^5
1 <= windowSize <= n
1 <= loads[i], threshold <= 10^9
```

#### Approach

Use sliding window sum. Maintain the sum of elements in the current window of size windowSize. At each step i >= windowSize - 1, check if windowSum > threshold * windowSize. If so, add index i to the result.

#### Intuition

To avoid floating-point inaccuracies, compare windowSum > (long)threshold * windowSize instead of dividing.

#### Algorithm

- Step 1: Calculate sum of the first windowSize elements.
- Step 2: Check condition for i = windowSize - 1.
- Step 3: Slide window from windowSize to n - 1: add loads[i], subtract loads[i - windowSize].
- Step 4: Check condition at each step and collect index.
- Step 5: Return collected indices.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static List<Integer> detectHighLoadWindows(int[] loads, int windowSize, int threshold) {
        List<Integer> result = new ArrayList<>();
        int n = loads.length;
        if (n < windowSize) return result;

        long windowSum = 0;
        for (int i = 0; i < windowSize; i++) {
            windowSum += loads[i];
        }

        long target = (long) threshold * windowSize;
        if (windowSum > target) result.add(windowSize - 1);

        for (int i = windowSize; i < n; i++) {
            windowSum += loads[i] - loads[i - windowSize];
            if (windowSum > target) {
                result.add(i);
            }
        }
        return result;
    }
}
```

#### Complexity

- **Time Complexity:** O(N) time
- **Space Complexity:** O(1) auxiliary space

### 1. Frog Position After T Seconds

- **Companies:** Inmobi
- **Years:** 2024
- **Category:** Graph
- **Difficulty:** Hard
- **Type:** Coding
- **Source:** `CDC Placement Preparations 2025-2026.xlsx`
- **Verified Link:** [Frog Position After T Seconds](https://leetcode.com/problems/frog-position-after-t-seconds/)

#### Question

Given an undirected tree consisting of n vertices numbered from 1 to n. A frog starts at vertex 1. In one second, the frog jumps from its current vertex to another unvisited vertex with equal probability. If the frog can not jump to any unvisited vertex, it stays on the same vertex forever. Find the probability that after t seconds the frog is on the vertex target.

#### Constraints

```
1 <= n <= 100
edges.length == n - 1
1 <= t <= 50
1 <= target <= n
```

#### Approach

Run BFS or DFS from vertex 1. Track the current probability and elapsed time. For a node u, count its unvisited neighbors. If it has unvisited neighbors, the probability splits equally (prob / unvisited_neighbors) and time increments. If a node has no unvisited neighbors, the frog remains on that node for all remaining time.

#### Intuition

Tree BFS tracking (node, time, probability). The frog either lands exactly at target at time t, or reaches target before time t and has nowhere else to jump.

#### Algorithm

- Step 1: If target == 1 and n == 1, return 1.0.
- Step 2: Build tree adjacency list.
- Step 3: Run BFS with Queue storing (node, parent, time, probability).
- Step 4: At each node u, count unvisited children.
- Step 5: If u == target: if time == t or (time < t && unvisited_children == 0), return probability; else return 0.0.
- Step 6: Enqueue each unvisited child with prob / unvisited_children and time + 1.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static double frogPosition(int n, int[][] edges, int t, int target) {
        if (n == 1) return 1.0;
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i <= n; i++) adj.add(new ArrayList<>());
        for (int[] e : edges) {
            adj.get(e[0]).add(e[1]);
            adj.get(e[1]).add(e[0]);
        }

        boolean[] visited = new boolean[n + 1];
        Queue<Object[]> q = new LinkedList<>();
        // Object: [node, time, prob]
        q.offer(new Object[]{1, 0, 1.0});
        visited[1] = true;

        while (!q.isEmpty()) {
            Object[] curr = q.poll();
            int u = (int) curr[0];
            int time = (int) curr[1];
            double prob = (double) curr[2];

            int unvisitedCount = 0;
            for (int v : adj.get(u)) {
                if (!visited[v]) unvisitedCount++;
            }

            if (u == target) {
                if (time == t || (time < t && unvisitedCount == 0)) return prob;
                return 0.0;
            }

            if (time < t && unvisitedCount > 0) {
                for (int v : adj.get(u)) {
                    if (!visited[v]) {
                        visited[v] = true;
                        q.offer(new Object[]{v, time + 1, prob / unvisitedCount});
                    }
                }
            }
        }
        return 0.0;
    }
}
```

#### Complexity

- **Time Complexity:** O(N) BFS
- **Space Complexity:** O(N) space

#### Question

Given an array with duplicate values, partition all its elements into two arrays of equal size such that neither array contains duplicate elements. Return the two arrays if a solution exists, or an empty list if impossible.

#### Constraints

```
Array length is even
1 <= arr.length <= 10^5
```

#### Approach

Count the frequency of each distinct element. If ANY element has frequency > 2, it is impossible to partition into two duplicate-free arrays (Pigeonhole principle), so return empty. Elements with frequency 2 MUST have one copy in array 1 and one copy in array 2. Elements with frequency 1 can be distributed to balance the sizes of the two arrays until both have size n / 2.

#### Intuition

Each array can hold at most 1 copy of any element. Balance unique items between the two partitions.

#### Algorithm

- Step 1: If array length is odd, return empty.
- Step 2: Build frequency map. If any freq > 2, return empty.
- Step 3: Put one copy of freq-2 elements into list1 and the other into list2.
- Step 4: Distribute freq-1 elements between list1 and list2 to make sizes equal.
- Step 5: If sizes cannot be made equal to n/2, return empty; else return both lists.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static List<List<Integer>> partitionEqualNoDups(int[] arr) {
        int n = arr.length;
        if (n % 2 != 0) return new ArrayList<>();

        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : arr) freq.put(x, freq.getOrDefault(x, 0) + 1);

        for (int count : freq.values()) {
            if (count > 2) return new ArrayList<>();
        }

        List<Integer> list1 = new ArrayList<>();
        List<Integer> list2 = new ArrayList<>();

        for (Map.Entry<Integer, Integer> e : freq.entrySet()) {
            if (e.getValue() == 2) {
                list1.add(e.getKey());
                list2.add(e.getKey());
            }
        }

        for (Map.Entry<Integer, Integer> e : freq.entrySet()) {
            if (e.getValue() == 1) {
                if (list1.size() < n / 2) {
                    list1.add(e.getKey());
                } else {
                    list2.add(e.getKey());
                }
            }
        }

        if (list1.size() != n / 2 || list2.size() != n / 2) return new ArrayList<>();
        return List.of(list1, list2);
    }
}
```

- **Time Complexity:** O(N) time
- **Space Complexity:** O(N) space

### 1. Max Subset Sum Equal to X with Queue Updates

- **Companies:** Media.net
- **Years:** 2023, 2024
- **Category:** Dynamic Programming
- **Difficulty:** Hard
- **Type:** Coding
- **Source:** `OneDrive_1_7-24-2024/Placement/Media.net/question.txt`
- **Verified Link:** [Max Subset Sum Equal to X with Queue Updates](https://codeforces.com/blog/entry/83441)

#### Question

You manage a queue of elements. Process Q queries of types: 1) Pop element from front of queue. 2) Push given element X to back of queue. 3) Find the length of the maximum subset of current elements whose sum equals a given value X. Constraints: X is in range 1..350, Q is up to 10^5.

#### Constraints

```
1 <= X <= 350
1 <= Q <= 10^5
```

#### Approach

Since X <= 350 is small, this is a 0/1 knapsack where we maintain the maximum subset size that achieves each sum 0..350. However, standard knapsack supports adding an element, but removing an element from a queue is FIFO. To implement a queue with 0/1 knapsack, use the Two Stacks technique: maintain an 'in-stack' and 'out-stack'. Each stack maintains its DP state array (where dp[w] = max subset length for sum w). Pushing to in-stack updates DP in O(X). Popping from out-stack pops its top DP state in O(1). If out-stack is empty, transfer all in-stack elements to out-stack, rebuilding the out-stack DP states. Combining the tops of in-stack and out-stack takes O(X). Total amortized cost per query is O(X) = O(350).

#### Intuition

Two-stack queue simulation combined with knapsack DP allows undoing arbitrary queue deletions in amortized O(X).

#### Algorithm

- Step 1: Maintain in-stack and out-stack with history of dp arrays.
- Step 2: Push: compute new dp array from top of in-stack and push.
- Step 3: Pop: if out-stack empty, transfer in-stack to out-stack one by one and recompute dp.
- Step 4: Query X: max over s in 0..X of (in_dp[s] + out_dp[X - s]).
- Step 5: Return max subset length.

#### Java Solution

```java
import java.util.*;

public class Solution {
    // Dynamic programming over queue using Two-Stack Knapsack technique
    static final int MAX_X = 350;

    static class DPStack {
        List<Integer> elements = new ArrayList<>();
        List<int[]> dpHistory = new ArrayList<>();

        DPStack() {
            int[] init = new int[MAX_X + 1];
            Arrays.fill(init, -1);
            init[0] = 0;
            dpHistory.add(init);
        }

        void push(int val) {
            elements.add(val);
            int[] prev = dpHistory.get(dpHistory.size() - 1);
            int[] next = prev.clone();
            for (int w = MAX_X; w >= val; w--) {
                if (prev[w - val] != -1) {
                    next[w] = Math.max(next[w], prev[w - val] + 1);
                }
            }
            dpHistory.add(next);
        }

        void pop() {
            elements.remove(elements.size() - 1);
            dpHistory.remove(dpHistory.size() - 1);
        }

        int[] getDP() {
            return dpHistory.get(dpHistory.size() - 1);
        }

        boolean isEmpty() {
            return elements.isEmpty();
        }
    }

    public static int queryMaxSubset(DPStack inStack, DPStack outStack, int X) {
        int[] dpIn = inStack.getDP();
        int[] dpOut = outStack.getDP();
        int maxLen = -1;
        for (int s = 0; s <= X; s++) {
            if (dpIn[s] != -1 && dpOut[X - s] != -1) {
                maxLen = Math.max(maxLen, dpIn[s] + dpOut[X - s]);
            }
        }
        return maxLen;
    }
}
```

#### Complexity

- **Time Complexity:** O(Q * X) amortized
- **Space Complexity:** O(N * X)

#### Sample Test Cases

**Test Case 1:**
- **Input:** `Push 10, Push 20, Query 30`
- **Output:** `2`

**Test Case 2:**
- **Input:** `Push 5, Pop, Query 5`
- **Output:** `-1`

- Step 3: A valid answer must resolve differences between words[0] and words[j]. Specifically, the valid string must agree with words[0] on all but at most one index, and with words[j] on all but at most one index. Identify mismatch indices between words[0] and words[j]. If mismatch count > 2, no valid string can satisfy both, return empty string.
- Step 4: Test candidate mutations that match words[0] except at one mismatch index.
- Step 5: For each candidate, check all N strings. If valid, return it; otherwise return empty string.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static String solution(String[] words) {
        int n = words.length;
        int k = words[0].length();

        // Find a word with >= 2 differences with words[0]
        int diffWordIdx = -1;
        for (int i = 1; i < n; i++) {
            if (countDiff(words[0], words[i]) >= 2) {
                diffWordIdx = i;
                break;
            }
        }

        if (diffWordIdx == -1) {
            return words[0];
        }

        // Collect mismatch indices between words[0] and words[diffWordIdx]
        List<Integer> diffIndices = new ArrayList<>();
        for (int j = 0; j < k; j++) {
            if (words[0].charAt(j) != words[diffWordIdx].charAt(j)) {
                diffIndices.add(j);
            }
        }

        if (diffIndices.size() > 2) {
            return "";
        }

        // Candidates can only come from changing words[0] at one of the diffIndices
        List<String> candidates = new ArrayList<>();
        for (int idx : diffIndices) {
            char[] arr = words[0].toCharArray();
            arr[idx] = words[diffWordIdx].charAt(idx);
            candidates.add(new String(arr));
        }

        for (String cand : candidates) {
            boolean valid = true;
            for (String w : words) {
                if (countDiff(cand, w) > 1) {
                    valid = false;
                    break;
                }
            }
            if (valid) return cand;
        }

        return "";
    }

    private static int countDiff(String a, String b) {
        int diff = 0;
        for (int i = 0; i < a.length(); i++) {
            if (a.charAt(i) != b.charAt(i)) {
                diff++;
                if (diff > 2) return diff;
            }
        }
        return diff;
    }
}
```

#### Complexity

- **Time Complexity:** O(N * K)
- **Space Complexity:** O(K) auxiliary space

### 2. Optimal Path Minimum Maximum Value

- **Companies:** Microsoft
- **Years:** 2024
- **Category:** Dynamic Programming
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `OA-2024/Microsoft-24.pdf`
- **Verified Link:** [Optimal Path Minimum Maximum Value](https://leetcode.com/problems/grid-game/)

#### Question

You are given two arrays, A and B, each made of N integers. They represent a grid with N columns and 2 rows, where A is the upper row and B is the lower row. Your task is to go from upper-left cell A[0] to bottom-right cell B[N-1] moving only right and down, so that the maximum value over which you pass is as small as possible. Return the maximum value on the optimal path.

#### Constraints

```
1 <= N <= 100,000
-10^9 <= A[i], B[i] <= 10^9
```

#### Approach

Since you can only move right and down, in a 2xN grid there is exactly one downward step! If you move down at column i (0 <= i < N), the path visits A[0..i] and B[i..N-1]. The maximum value on this path is max(prefix_max(A, i), suffix_max(B, i)). We want to find the column i that minimizes this maximum value.

#### Intuition

In a 2xN grid, any path consists of staying on the top row until some column i, stepping down to the bottom row, and staying on the bottom row until the end. We precalculate prefix max of A and suffix max of B in linear time.

#### Algorithm

- Step 1: Precompute prefA[i] = max(prefA[i-1], A[i]) for i from 0 to N-1.
- Step 2: Precompute suffB[i] = max(suffB[i+1], B[i]) for i from N-1 down to 0.
- Step 3: Initialize minMax = infinity.
- Step 4: For each column i from 0 to N-1: pathMax = max(prefA[i], suffB[i]). Update minMax = min(minMax, pathMax).
- Step 5: Return minMax.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int solution(int[] A, int[] B, int N) {
        int[] prefA = new int[N];
        int[] suffB = new int[N];

        prefA[0] = A[0];
        for (int i = 1; i < N; i++) {
            prefA[i] = Math.max(prefA[i - 1], A[i]);
        }

        suffB[N - 1] = B[N - 1];
        for (int i = N - 2; i >= 0; i--) {
            suffB[i] = Math.max(suffB[i + 1], B[i]);
        }

        int ans = Integer.MAX_VALUE;
        for (int i = 0; i < N; i++) {
            int pathMax = Math.max(prefA[i], suffB[i]);
            ans = Math.min(ans, pathMax);
        }
        return ans;
    }
}
```

#### Complexity

- **Time Complexity:** O(N) time
- **Space Complexity:** O(N) auxiliary space

### 3. Shortest Compressed String after Removal

- **Companies:** Microsoft
- **Years:** 2024
- **Category:** Sliding Window
- **Difficulty:** Hard
- **Type:** Coding
- **Source:** `OA-2024/Microsoft-24.pdf`
- **Verified Link:** [Shortest Compressed String after Removal](https://leetcode.com/problems/string-compression-ii/)

#### Question

Run-length encoding replaces each segment of equal characters with its length followed by the character (single-character segments remain unchanged). Before compression, exactly K consecutive characters are removed from string S. Return the shortest possible length of the compressed representation after removing K consecutive characters.

#### Constraints

```
1 <= N <= 100,000
0 <= K <= N
S consists of uppercase English letters (A-Z)
```

#### Approach

When a window of size K from index i to i+K-1 is deleted, the remaining string consists of prefix S[0..i-1] and suffix S[i+K..N-1]. If S[i-1] == S[i+K], the two adjacent blocks merge into a single block of combined length. Precompute run-length segment encodings from left to right and right to left to evaluate remaining lengths in O(1) time per window of size K.

#### Intuition

Removing a subarray of fixed length K is a sliding window problem. The only interaction between the remaining prefix and suffix occurs at the seam i-1 and i+K.

#### Algorithm

- Step 1: If K == N, return 0.
- Step 2: Precalculate prefix RLE blocks and suffix RLE blocks.
- Step 3: For each window [i, i+K-1]: calculate RLE length of prefix + RLE length of suffix.
- Step 4: If characters before and after window match, adjust length for the merged block.
- Step 5: Track and return the minimum compressed length observed.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int solution(String S, int K) {
        int n = S.length();
        if (K >= n) return 0;

        int minLen = n;
        // Evaluate all windows [i, i+K-1]
        for (int i = 0; i <= n - K; i++) {
            StringBuilder sb = new StringBuilder();
            sb.append(S.substring(0, i));
            sb.append(S.substring(i + K));
            minLen = Math.min(minLen, compressLength(sb.toString()));
        }
        return minLen;
    }

    private static int compressLength(String s) {
        int len = 0;
        int n = s.length();
        int i = 0;
        while (i < n) {
            int j = i;
            while (j < n && s.charAt(j) == s.charAt(i)) {
                j++;
            }
            int count = j - i;
            if (count == 1) {
                len += 1;
            } else {
                len += 1 + String.valueOf(count).length();
            }
            i = j;
        }
        return len;
    }
}
```

- **Time Complexity:** O(N) with optimized prefix/suffix RLE caching
- **Space Complexity:** O(N) auxiliary space

### 4. Alphabetically Largest String Transformation

- **Companies:** Microsoft
- **Years:** 2024
- **Category:** Greedy
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `OA-2024/Microsoft-24.pdf`
- **Verified Link:** [Alphabetically Largest String Transformation](https://leetcode.com/discuss/interview-question/4549306/Microsoft-OA)

#### Question

There is a string of length N made only of letters 'a'. Whenever there are two identical adjacent letters (e.g. 'aa'), they can be transformed into a single letter of the next alphabet ('aa' -> 'b', 'bb' -> 'c', etc.). 'zz' cannot be further transformed. What is the alphabetically largest string that can be obtained from the initial string?

#### Constraints

```
1 <= N <= 1,000,000,000
```

#### Approach

Notice that two 'a's make one 'b', two 'b's make one 'c', etc. This directly corresponds to the binary representation of N! The bit at position 0 represents count of 'a', bit 1 represents 'b', ..., bit 25 represents 'z'. However, 'zz' cannot be transformed, so any overflow at 'z' remains as multiple 'z's. To make the string alphabetically largest, order characters in descending alphabetical order ('z' down to 'a').

#### Intuition

Combining pairs of identical letters is equivalent to base-2 carry addition. Bit i being 1 means one instance of the i-th letter of the alphabet is present.

#### Algorithm

- Step 1: Compute counts of letters: for letter 0 ('a') to 24 ('y'), letter[k] = N % 2, and N = N / 2.
- Step 2: For letter 25 ('z'), letter[25] = N (since 'zz' cannot be combined).
- Step 3: Construct the string starting from 'z' down to 'a' using the counts.
- Step 4: Return the constructed string.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static String solution(int N) {
        StringBuilder sb = new StringBuilder();
        int[] count = new int[26];
        long current = N;

        for (int i = 0; i < 25; i++) {
            count[i] = (int)(current % 2);
            current /= 2;
        }
        count[25] = (int)current; // all remaining value goes to 'z'

        // Build largest alphabetical string: largest characters first
        for (int i = 25; i >= 0; i--) {
            char ch = (char)('a' + i);
            for (int j = 0; j < count[i]; j++) {
                sb.append(ch);
            }
        }
        return sb.toString();
    }
}
```

#### Complexity

- **Time Complexity:** O(log N) time
- **Space Complexity:** O(log N) space for string output

### 5. Largest Sum without Common Digits

- **Companies:** Microsoft
- **Years:** 2024
- **Category:** Bit Manipulation
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `OA-2024/Microsoft-24.pdf`
- **Verified Link:** [Largest Sum without Common Digits](https://leetcode.com/problems/maximum-product-of-word-lengths/)

#### Question

Given an array A of N integers, find the largest sum of two numbers which do not have any common digits. If it is impossible to choose two such numbers, return -1.

#### Constraints

```
2 <= N <= 200,000
0 <= A[i] <= 1,000,000,000
```

#### Approach

Represent each number by a 10-bit mask where the d-th bit is 1 if digit d appears in the number. There are only 2^10 = 1024 possible digit masks! For each mask, find the maximum number in A with that mask. Then iterate over all pairs of disjoint masks (mask1 & mask2 == 0) and find the maximum sum max_val[mask1] + max_val[mask2].

#### Intuition

Although N is up to 200,000, the number of distinct digit subsets is at most 1024. Condensing numbers by their digit masks reduces the problem to checking disjoint mask pairs in O(2^10 * 2^10) = O(10^6) operations.

#### Algorithm

- Step 1: Create an array maxVal of size 1024 initialized to -1.
- Step 2: For each number x in A, compute its digit mask. Update maxVal[mask] = max(maxVal[mask], x).
- Step 3: Initialize max_sum = -1.
- Step 4: For mask1 from 0 to 1023: if maxVal[mask1] == -1 continue; for mask2 from mask1 to 1023: if (mask1 & mask2) == 0 and maxVal[mask2] != -1, update max_sum = max(max_sum, maxVal[mask1] + maxVal[mask2]).
- Step 5: Return max_sum.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int solution(int[] A) {
        int[] maxVal = new int[1024];
        Arrays.fill(maxVal, -1);

        for (int x : A) {
            int mask = getMask(x);
            maxVal[mask] = Math.max(maxVal[mask], x);
        }

        int maxSum = -1;
        for (int m1 = 0; m1 < 1024; m1++) {
            if (maxVal[m1] == -1) continue;
            for (int m2 = m1; m2 < 1024; m2++) {
                if ((m1 & m2) == 0 && maxVal[m2] != -1) {
                    maxSum = Math.max(maxSum, maxVal[m1] + maxVal[m2]);
                }
            }
        }
        return maxSum;
    }

    private static int getMask(int x) {
        if (x == 0) return 1;
        int mask = 0;
        while (x > 0) {
            mask |= (1 << (x % 10));
            x /= 10;
        }
        return mask;
    }
}
```

- **Time Complexity:** O(N * log10(maxA) + 4^5) = O(N + 10^6)
- **Space Complexity:** O(1) auxiliary space (1024 integers)

### 6. Minimum Swaps to Minimize Difference

- **Companies:** Microsoft
- **Years:** 2023, 2024
- **Category:** Greedy
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `OA-2024/Microsoft-24.pdf`
- **Verified Link:** [Minimum Swaps to Minimize Difference](https://leetcode.com/problems/minimum-swaps-to-make-sequences-increasing/)

#### Question

Given two strings S and T of digits of equal length N representing large integers, make the two numbers as close to each other as possible (minimize |S - T|). You can swap digits at the same position between S and T. Swapping is tiring, so minimize the number of swaps. Return the minimum number of swaps needed to achieve the minimum difference.

#### Constraints

```
1 <= N <= 100,000
S and T consist only of digits '0'-'9'
Neither contains leading zeros
```

#### Approach

At the first index where S[i] != T[i], one string must become strictly larger than the other. WLOG, assume S becomes larger. At this first difference, S[i] must take the larger digit and T[i] the smaller digit (1 swap if S[i] < T[i], 0 swaps if S[i] > T[i]). Once S is larger, to minimize (S - T), every subsequent index must minimize S[j] and maximize T[j], meaning S[j] should take min(S[j], T[j]) and T[j] should take max(S[j], T[j]). Count the swaps required. Do this symmetrically assuming T becomes larger and take the minimum swaps for the minimal difference.

#### Intuition

The highest order digit determines which number is larger. To minimize the absolute difference, the larger number should have all remaining digits as small as possible, while the smaller number should have all remaining digits as large as possible.

#### Algorithm

- Step 1: Find the first index i where S[i] != T[i]. If no such index, difference is 0 and swaps = 0.
- Step 2: Case 1: Make S larger at index i. For each subsequent index j, set S[j] = min(S[j], T[j]) and T[j] = max(S[j], T[j]). Count swaps.
- Step 3: Case 2: Make T larger at index i. For each subsequent index j, set T[j] = min(S[j], T[j]) and S[j] = max(S[j], T[j]). Count swaps.
- Step 4: Return min(swaps_case1, swaps_case2).

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int solution(String S, String T) {
        int n = S.length();
        int firstDiff = -1;
        for (int i = 0; i < n; i++) {
            if (S.charAt(i) != T.charAt(i)) {
                firstDiff = i;
                break;
            }
        }
        if (firstDiff == -1) return 0;

        // Case 1: S is greater
        int swaps1 = 0;
        char[] s1 = S.toCharArray();
        char[] t1 = T.toCharArray();
        if (s1[firstDiff] < t1[firstDiff]) {
            swaps1++;
            char tmp = s1[firstDiff];
            s1[firstDiff] = t1[firstDiff];
            t1[firstDiff] = tmp;
        }
        for (int i = firstDiff + 1; i < n; i++) {
            if (s1[i] > t1[i]) {
                swaps1++;
            }
        }

        // Case 2: T is greater
        int swaps2 = 0;
        char[] s2 = S.toCharArray();
        char[] t2 = T.toCharArray();
        if (t2[firstDiff] < s2[firstDiff]) {
            swaps2++;
            char tmp = s2[firstDiff];
            s2[firstDiff] = t2[firstDiff];
            t2[firstDiff] = tmp;
        }
        for (int i = firstDiff + 1; i < n; i++) {
            if (t2[i] > s2[i]) {
                swaps2++;
            }
        }

        return Math.min(swaps1, swaps2);
    }
}
```

#### Complexity

- **Time Complexity:** O(N) time
- **Space Complexity:** O(N) space

### 7. Minimum Cost to Equalize Array

- **Companies:** Microsoft
- **Years:** 2024
- **Category:** Greedy
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `OA-2024/Microsoft-24.pdf`
- **Verified Link:** [Minimum Cost to Equalize Array](https://leetcode.com/problems/minimum-cost-to-equalize-array/)

#### Question

Given an array A of N integers and two types of operations: increment a single element at cost C1, or increment two distinct elements at cost C2. Find the minimum total cost to make all elements in A equal. Return the result modulo 10^9.

#### Constraints

```
1 <= N <= 100,000
1 <= C1, C2 <= 10^9
0 <= A[i] <= 10^9
```

#### Approach

If 2 * C1 <= C2, it is always cheaper to use single increments exclusively. Otherwise, pair up increments as much as possible using cost C2. All elements must reach at least max(A) = M. Calculate the deficit d[i] = M - A[i]. Let total deficit be S = sum(d[i]) and max individual deficit be D_max = max(d[i]). We can pair up at most min(S / 2, S - D_max) operations.

#### Intuition

This is equivalent to greedy scheduling where increments to the dominant element cannot be paired with each other, but any other increments can be paired.

#### Algorithm

- Step 1: If 2 * C1 <= C2, cost is sum(M - A[i]) * C1 modulo 10^9.
- Step 2: Otherwise, target can be M or M + 1 (to parity balance). Calculate pairings.
- Step 3: Number of paired operations is min(S / 2, S - D_max). Remainder is done with single increments.
- Step 4: Return minimum cost modulo 10^9.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int solution(int[] A, int N, int C1, int C2) {
        long MOD = 1_000_000_000L;
        long maxVal = 0;
        for (int x : A) maxVal = Math.max(maxVal, x);

        if (2L * C1 <= C2) {
            long totalCost = 0;
            for (int x : A) totalCost = (totalCost + (maxVal - x) * C1) % MOD;
            return (int) totalCost;
        }

        long minCost = Long.MAX_VALUE;
        // Test targets maxVal and maxVal + 1
        for (long target = maxVal; target <= maxVal + 2; target++) {
            long totalDeficit = 0;
            long maxDeficit = 0;
            for (int x : A) {
                long d = target - x;
                totalDeficit += d;
                maxDeficit = Math.max(maxDeficit, d);
            }
            long pairs = Math.min(totalDeficit / 2, totalDeficit - maxDeficit);
            long singles = totalDeficit - 2 * pairs;
            long cost = pairs * C2 + singles * C1;
            minCost = Math.min(minCost, cost);
        }
        return (int) (minCost % MOD);
    }
}
```

- **Time Complexity:** O(N) time
- **Space Complexity:** O(1) auxiliary space

```java
public class Solution {

        if (root == null) return null;

            root.right = new TreeNode(root.val);
```

### 9. Reorder Routes to City Zero

- **Companies:** Microsoft
- **Years:** 2023
- **Category:** Graph
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `OA-2024/Microsoft-23.pdf`
- **Verified Link:** [Reorder Routes to City Zero](https://leetcode.com/problems/reorder-routes-to-make-all-paths-lead-to-the-city-zero/)

#### Question

There is a network of N + 1 cities labeled 0 to N connected by N narrow 1-way roads forming a tree. A big hospital was founded in city 0. Reorient the minimum number of roads so that everyone can reach city 0.

#### Constraints

```
N is within [1..100,000]
Graph forms a valid tree
```

#### Approach

Build an undirected adjacency list where each directed edge u -> v is stored as (v, cost=1) and backwards as (u, cost=0). Traverse outward from city 0 using BFS or DFS. Any edge that points away from 0 needs to be flipped (costs 1).

#### Intuition

Starting from city 0, traversing to neighbors requires all roads to point towards 0. Edges directed away from 0 must be reversed.

#### Algorithm

- Step 1: Construct adjacency list with edge directions: for edge A[i] -> B[i], add (B[i], 1) to adj[A[i]] and (A[i], 0) to adj[B[i]].
- Step 2: Start BFS/DFS from node 0 with visited array.
- Step 3: For each unvisited neighbor, add edge direction cost to answer and traverse.
- Step 4: Return total reversals.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int minReorder(int n, int[][] connections) {
        List<List<int[]>> adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
        for (int[] c : connections) {
            adj.get(c[0]).add(new int[]{c[1], 1}); // 1 = needs reversal if traversed
            adj.get(c[1]).add(new int[]{c[0], 0}); // 0 = correct direction towards 0
        }

        boolean[] visited = new boolean[n];
        Queue<Integer> queue = new LinkedList<>();
        queue.offer(0);
        visited[0] = true;
        int reversals = 0;

        while (!queue.isEmpty()) {
            int node = queue.poll();
            for (int[] edge : adj.get(node)) {
                int next = edge[0];
                int cost = edge[1];
                if (!visited[next]) {
                    visited[next] = true;
                    reversals += cost;
                    queue.offer(next);
                }
```

#### Question

You have M square tiles of size 1x1 and N square tiles of size 2x2. Create the largest possible square using these tiles without overlapping and without empty spaces. Return the side length of the largest square that can be formed.

#### Constraints

```
0 <= M, N <= 1,000,000,000
```

#### Approach

Binary search on the square side length L. Total area needed is L^2. The 2x2 tiles can only cover a 2x2 area; in a square of size L, the maximum number of 2x2 tiles that can fit without overlapping is (L/2) * (L/2). The remaining area must be covered by 1x1 tiles. Thus, side length L is feasible if: floor(L / 2)^2 <= N and (L^2 - 4 * min(N, floor(L/2)^2)) <= M.

#### Intuition

Every 2x2 tile covers 4 units of area on even grid lines. Any area not covered by 2x2 tiles must be filled with 1x1 tiles.

#### Algorithm

- Step 1: Set low = 0, high = (int)Math.sqrt(M + 4L * N).
- Step 2: While low <= high, set mid = low + (high - low) / 2.
- Step 3: max_2x2_can_fit = (mid / 2) * (mid / 2).
- Step 4: used_2x2 = min(N, max_2x2_can_fit).
- Step 5: required_1x1 = mid * mid - 4 * used_2x2.
- Step 6: If required_1x1 <= M, ans = mid, search higher (low = mid + 1); else search lower (high = mid - 1).
- Step 7: Return ans.

#### Java Solution

```java
public class Solution {
    public static int solution(int M, int N) {
        long low = 0;
        long high = 2_000_000_000L;
        long ans = 0;

        while (low <= high) {
            long mid = low + (high - low) / 2;
            long max2x2Fit = (mid / 2) * (mid / 2);
            long used2x2 = Math.min((long)N, max2x2Fit);
            long areaNeeded = mid * mid;
            long areaCoveredBy2x2 = used2x2 * 4L;
            long needed1x1 = areaNeeded - areaCoveredBy2x2;

            if (needed1x1 <= M) {
                ans = mid;
                low = mid + 1;
            } else {
                high = mid - 1;
            }
        }
        return (int) ans;
    }
}
```

There are N tiles, each made of two colored squares ('R' or 'G'), described by 2-character strings ('RR', 'GR', 'RG', 'GG'). Tiles cannot be rotated. Two tiles can be placed next to each other if the color of their adjacent squares is identical. What is the length of the longest possible sequence that can be created using the provided tiles?

#### Constraints

```
1 <= N <= 100,000
strings are 'RR', 'GR', 'RG', or 'GG'
```

#### Approach

Model as finding the longest path in a directed multigraph with 2 vertices: 'R' and 'G'. 'RR' is a self-loop on R, 'GG' is a self-loop on G, 'RG' is a directed edge R -> G, and 'GR' is a directed edge G -> R. Count occurrences of each tile: cntRR, cntGG, cntRG, cntGR. A sequence alternates between R and G using RG and GR edges, inserting all self-loops RR while at R, and GG while at G.

#### Intuition

Self loops can be fully consumed whenever we visit their vertex. The number of alternations between R and G is limited by min(cntRG, cntGR).

#### Algorithm

- Step 1: Count occurrences of 'RR', 'GG', 'RG', and 'GR'.
- Step 2: If cntRG == cntGR: we can use all RG and GR tiles, alternating R->G and G->R. Add all RR and GG tiles.
- Step 3: If cntRG != cntGR: we can take min(cntRG, cntGR) + 1 alternating transitions, plus all matching self-loops.
- Step 4: Handle edge cases where only self-loops exist (e.g., only RR or only GG).
- Step 5: Return max sequence length.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int solution(String[] A) {
        int rr = 0, gg = 0, rg = 0, gr = 0;
        for (String s : A) {
            if (s.equals("RR")) rr++;
            else if (s.equals("GG")) gg++;
            else if (s.equals("RG")) rg++;
            else if (s.equals("GR")) gr++;
        }

        if (rg == 0 && gr == 0) {
            return Math.max(rr, gg);
        }

        if (rg == gr) {
            return rr + gg + 2 * rg;
        } else {
            int transitions = 2 * Math.min(rg, gr) + 1;
            return rr + gg + transitions;
        }
    }
}
```

### 13. Smallest Integer without Consecutive Duplicate Digits

- **Companies:** Microsoft
- **Years:** 2023
- **Category:** Math
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `OneDrive_1_7-24-2024/Placement/Microsoft/Microsoft/Intern/Microsoft_questions.pdf`
- **Verified Link:** [Smallest Integer without Consecutive Duplicate Digits](https://leetcode.com/problems/numbers-with-same-consecutive-differences/)

#### Question

Given positive integer N, find the smallest integer strictly greater than N that does not contain two identical consecutive digits.

#### Constraints

```
1 <= N <= 1,000,000,000
```

#### Approach

Start with N + 1. Convert to string. Scan from left to right to find the first index i where digit[i] == digit[i-1]. If found, increment digit[i]. If digit[i] becomes 10, propagate carry to the left and repeat scan. Once digit[i] is incremented, make all subsequent digits to the right as small as possible: alternate 0 and 1 starting at index i + 1 (using 0 if different from previous digit, else 1).

#### Intuition

Incrementing the most significant violating digit and resetting all less significant digits greedily to minimal alternating digits produces the smallest valid integer.

#### Algorithm

- Step 1: Start with S = String.valueOf(N + 1).
- Step 2: Find first index i where S[i] == S[i-1].
- Step 3: Increment S[i]. Handle carry leftwards if S[i] > '9'.
- Step 4: For all positions j > i, fill with the smallest digit != S[j-1].
- Step 5: Return result as integer.

#### Java Solution

```java
public class Solution {
    public static int solution(int N) {
        char[] s = String.valueOf(N + 1).toCharArray();
        int i = 1;
        while (i < s.length) {
            if (s[i] == s[i - 1]) {
                // Increment s[i]
                int carryIdx = i;
                while (carryIdx >= 0 && s[carryIdx] == '9') {
                    carryIdx--;
                }
                if (carryIdx < 0) {
                    char[] next = new char[s.length + 1];
                    next[0] = '1';
                    for (int j = 1; j < next.length; j++) next[j] = (j % 2 == 1) ? '0' : '1';
                    return Integer.parseInt(new String(next));
                }
                s[carryIdx]++;
                for (int j = carryIdx + 1; j < s.length; j++) {
                    s[j] = (s[j - 1] == '0') ? '1' : '0';
                }
                i = 1; // Restart scan
            } else {
                i++;
            }
        }
        return Integer.parseInt(new String(s));
    }
}
```

- **Time Complexity:** O(log10(N))
- **Space Complexity:** O(log10(N))

### 1. Count Arrays with Difference At Most 1

- **Companies:** Pace Stock
- **Years:** 2024
- **Category:** Dynamic Programming
- **Difficulty:** Hard
- **Type:** Coding
- **Source:** `int-service/Pace stock_.docx`
- **Verified Link:** [Count Arrays with Difference At Most 1](https://codeforces.com/problemset/problem/1288/C)

#### Question

An array of length N is given where elements are in range [0..10^9]. A value of 0 means the number is unknown. Find the number of valid arrays such that the absolute difference between consecutive elements is at most 1 (|A[i] - A[i-1]| <= 1). Constraints: N <= 1500.

#### Constraints

```
1 <= N <= 1500
0 <= A[i] <= 10^9
```

#### Approach

Because adjacent difference is at most 1, the values can only vary by at most N from any known non-zero element! Collect all known elements; their values bound the reachable range to at most 2 * N distinct values. Coordinate compress the active range of values. Use DP: dp[i][v] = count of valid prefixes of length i ending with value v. For unknown A[i] = 0, dp[i][v] = dp[i-1][v-1] + dp[i-1][v] + dp[i-1][v+1]. Use rolling prefix sums to compute in O(N * (2N)) = O(N^2) time.

#### Intuition

Bounded step size |diff| <= 1 restricts the universe of possible values around known anchors to at most O(N), making O(N^2) DP tractable.

#### Algorithm

- Step 1: Check known anchors. If |A[i] - A[j]| > |i - j|, return 0.
- Step 2: Identify min and max possible values around the anchors, remapping to 0..2N.
- Step 3: dp[v] initialized for first element.
- Step 4: Transition: dp_next[v] = dp[v-1] + dp[v] + dp[v+1].
- Step 5: Return sum(dp[v]) modulo 10^9 + 7.

#### Java Solution

```java
import java.util.*;

public class Solution {
    static final long MOD = 1_000_000_007L;

    public static int countArrays(int[] A) {
        int n = A.length;
        // If all 0s, unbounded unless minimum bound 1 is assumed. Assuming values in [1..M]
        int maxVal = 2 * n + 5;
        long[] dp = new long[maxVal + 2];

        if (A[0] != 0) {
            if (A[0] >= maxVal) return 0;
            dp[A[0]] = 1;
        } else {
            for (int v = 1; v <= maxVal; v++) dp[v] = 1;
        }

        for (int i = 1; i < n; i++) {
            long[] next = new long[maxVal + 2];
            if (A[i] != 0) {
                int v = A[i];
                if (v < maxVal) {
                    next[v] = (dp[v - 1] + dp[v] + dp[v + 1]) % MOD;
                }
            } else {
                for (int v = 1; v <= maxVal; v++) {
                    next[v] = (dp[v - 1] + dp[v] + dp[v + 1]) % MOD;
                }
            }
            dp = next;
        }

        long total = 0;
        for (long val : dp) total = (total + val) % MOD;
        return (int) total;
    }
}
```

#### Complexity

- **Time Complexity:** O(N^2)
- **Space Complexity:** O(N)

### 1. Olympic Hurdles / Max Score with At Most K Consecutive

- **Companies:** PhonePe
- **Years:** 2024
- **Category:** Dynamic Programming
- **Difficulty:** Hard
- **Type:** Coding
- **Source:** `OA-2024/Phonepay-NIT-NGPR.pdf`

#### Question

There are n ordered hurdles, each with score[i]. An athlete can jump at most k consecutive hurdles before they must remove a hurdle. The athlete wants to remove hurdles to maximize the total score of the remaining hurdles they cross. (Equivalently, minimize the sum of removed hurdles such that in any window of size k + 1, at least one hurdle is removed). Find the maximum score achievable.

#### Constraints

```
1 <= n <= 10^5
1 <= k <= n
0 <= score[i] <= 2 * 10^9
```

#### Approach

Maximizing remaining score is equivalent to minimizing removed score: Total_Score - min_removed. To ensure at most k consecutive hurdles are crossed, out of every (k + 1) consecutive hurdles, at least one must be removed! Let dp[i] be the minimum cost of removed hurdles such that hurdle i is removed and the constraint is satisfied up to i. dp[i] = score[i] + min_{max(0, i - k - 1) <= j < i} dp[j]. Use a monotonic deque (Sliding Window Minimum) to find min(dp[j]) in O(1) time per transition.

#### Intuition

Duality transforms 'at most k consecutive taken' into 'at least 1 in every k+1 removed', which is solved in O(N) using DP with a monotonic deque.

#### Algorithm

- Step 1: Compute total sum of all scores.
- Step 2: Initialize dp array of size n + 1 and a deque storing indices.
- Step 3: dp[i] = score[i - 1] + (deque.isEmpty() ? 0 : dp[deque.peekFirst()]).
- Step 4: Maintain deque elements in increasing order of dp values, popping elements out of the window [i - k, i - 1].
- Step 5: The answer for min_removed is min(dp[j]) for j in [n - k, n]. Max score = totalSum - min_removed.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static long maxHurdlesScore(int n, int k, long[] score) {
        long totalSum = 0;
        for (long s : score) totalSum += s;
        if (k >= n) return totalSum;

        long[] dp = new long[n + 1];
        Deque<Integer> dq = new ArrayDeque<>();
        dq.offer(0); // dp[0] = 0

        for (int i = 1; i <= n; i++) {
            while (!dq.isEmpty() && dq.peekFirst() < i - k - 1) {
                dq.pollFirst();
            }
            dp[i] = score[i - 1] + dp[dq.peekFirst()];

            while (!dq.isEmpty() && dp[dq.peekLast()] >= dp[i]) {
                dq.pollLast();
            }
            dq.offerLast(i);
        }

        long minRemoved = Long.MAX_VALUE;
        for (int i = n - k; i <= n; i++) {
            minRemoved = Math.min(minRemoved, dp[i]);
        }
        return totalSum - minRemoved;
    }
}
```

#### Complexity

- **Time Complexity:** O(N) with Monotonic Deque
- **Space Complexity:** O(N) space

```java
import java.util.*;

public class Solution {
    public static long latestArrivalTime(long[] eventTimes, int casesPerEvent, long[] lawyerTimes) {
        Arrays.sort(eventTimes);
        Arrays.sort(lawyerTimes);

        long low = 0, high = eventTimes[eventTimes.length - 1];
        long ans = -1;

        while (low <= high) {
            long mid = low + (high - low) / 2;
            if (canGetCase(eventTimes, casesPerEvent, lawyerTimes, mid)) {
                ans = mid;
                low = mid + 1;
            } else {
                high = mid - 1;
            }
        }
        return ans;

    private static boolean canGetCase(long[] events, int capacity, long[] lawyers, long mikeTime) {
        int lIdx = 0;
        int nLawyers = lawyers.length;
        boolean mikeJoined = false;
        PriorityQueue<Long> pq = new PriorityQueue<>();

        for (long eTime : events) {
            while (lIdx < nLawyers && lawyers[lIdx] <= eTime) {
                pq.offer(lawyers[lIdx++]);
            }
            if (!mikeJoined && mikeTime <= eTime) {
                pq.offer(mikeTime);
                mikeJoined = true;
            }

            int distributed = 0;
            while (!pq.isEmpty() && distributed < capacity) {
                long served = pq.poll();
                distributed++;
                if (served == mikeTime) return true;
            }
        }
        return false;
    }
}
```

- **Companies:** PhonePe
- **Years:** 2024
- **Category:** Graph
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `OA-2024/Phonepay-NIT-NGPR.pdf`
- **Verified Link:** [Dora The Explorer / Vacation with Single Mode Switch](https://leetcode.com/problems/network-delay-time/)

#### Question

Dora is vacationing on an archipelago of N islands, traveling from island S to island E. She must travel using Boat only for the first part of the vacation and Plane only for the second part (switching mode exactly once at some intermediate island I, which can be S or E). Given N x N matrix B for boat costs and P for plane costs (-1 if no travel possible), find the minimum cost to complete the vacation.

#### Constraints

```
3 <= N <= 1250
1 <= S, E <= N
1 <= B[i][j], P[i][j] <= 100
```

#### Approach

Run Dijkstra from start island S on matrix B to find distB_S[i] (shortest boat path from S to all islands). Run Dijkstra from end island E on reversed matrix P to find distP_E[i] (shortest plane path from all islands to E). Symmetrically, if plane is used first and boat second, run Dijkstra from S on P and from E on B. The minimum cost is min over all intermediate islands i of (dist1[i] + dist2[i]).

#### Intuition

Switching transportation mode once divides the path into two subpaths, each solved by Dijkstra from endpoints.

#### Algorithm

- Step 1: Compute shortest boat distances from S to all nodes: distBoatFromS.
- Step 2: Compute shortest plane distances from all nodes to E: distPlaneToE.
- Step 3: For each island i: minCost = min(minCost, distBoatFromS[i] + distPlaneToE[i]).
- Step 4: Also check symmetric case (plane first, boat second).
- Step 5: Return minCost (or -1 if unreachable).

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int minVacationCost(int n, int[][] B, int[][] P, int S, int E) {
        int[] distB = dijkstra(n, B, S);
        int[] distP = dijkstra(n, P, E); // Plane to E (or from E in symmetric graph)

        int ans = Integer.MAX_VALUE;
        for (int i = 1; i <= n; i++) {
            if (distB[i] != Integer.MAX_VALUE && distP[i] != Integer.MAX_VALUE) {
                ans = Math.min(ans, distB[i] + distP[i]);
            }
        }
        return ans == Integer.MAX_VALUE ? -1 : ans;
    }

    private static int[] dijkstra(int n, int[][] cost, int start) {
        int[] d = new int[n + 1];
        Arrays.fill(d, Integer.MAX_VALUE);
        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        d[start] = 0;
        pq.offer(new int[]{0, start});

        while (!pq.isEmpty()) {
            int[] curr = pq.poll();
            int dist = curr[0], u = curr[1];
            if (dist > d[u]) continue;

            for (int v = 1; v <= n; v++) {
                if (cost[u - 1][v - 1] != -1) {
                    int w = cost[u - 1][v - 1];
                    if (d[u] + w < d[v]) {
                        d[v] = d[u] + w;
                        pq.offer(new int[]{d[v], v});
                    }
                }
            }
        }
        return d;
    }
}
```

#### Complexity

- **Time Complexity:** O(N^2 log N)
- **Space Complexity:** O(N)

### 1. Maximum Employees to Be Invited to a Meeting

- **Companies:** Piramal
- **Years:** 2024
- **Category:** Graph
- **Difficulty:** Hard
- **Type:** Coding
- **Source:** `CDC Placement Preparations 2025-2026.xlsx`
- **Verified Link:** [Maximum Employees to Be Invited to a Meeting](https://leetcode.com/problems/maximum-employees-to-be-invited-to-a-meeting/)

#### Question

A company has n employees numbered 0 to n - 1. Each employee has a favorite person favorite[i] they must sit next to at a round table. Find the maximum number of employees that can be invited to the meeting.

#### Constraints

```
2 <= n <= 10^5
0 <= favorite[i] <= n - 1
favorite[i] != i
```

#### Approach

This is a functional graph where each node has out-degree 1. Any functional graph decomposes into components, each with a single directed cycle and trees rooted on the cycle. There are two valid table configurations: 1) A single cycle of length >= 3 (everyone in the cycle sits together). 2) Multiple independent pairs of mutually favorite employees (cycles of length 2): for each pair (u, v) with favorite[u] == v and favorite[v] == u, we can attach the longest chain leading into u and the longest chain leading into v! All such 2-cycles and their arm chains can sit together at the table. Answer is max(largest_cycle >= 3, sum_of_all_2_cycles_with_arms).

#### Intuition

Cycles of size 2 permit branches to extend on both sides, while cycles of size >= 3 must be strictly closed without branches.

#### Algorithm

- Step 1: Compute in-degree of all nodes and use Kahn's algorithm (topological sort) to prune tree branches, calculating the longest branch length depth[u] reaching each node.
- Step 2: Traverse remaining nodes to identify cycles.
- Step 3: If cycle length == 2: sum_2_cycles += 2 + depth[u] + depth[v].
- Step 4: If cycle length >= 3: max_cycle = max(max_cycle, cycle_len).
- Step 5: Return max(max_cycle, sum_2_cycles).

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int maximumInvitations(int[] favorite) {
        int n = favorite.length;
        int[] inDegree = new int[n];
        for (int f : favorite) inDegree[f]++;

        Queue<Integer> q = new LinkedList<>();
        int[] depth = new int[n]; // max chain depth into node
        for (int i = 0; i < n; i++) {
            if (inDegree[i] == 0) q.offer(i);
        }

        while (!q.isEmpty()) {
            int u = q.poll();
            int v = favorite[u];
            depth[v] = Math.max(depth[v], depth[u] + 1);
            if (--inDegree[v] == 0) q.offer(v);
        }

        int maxCycle = 0;
        int sum2Cycles = 0;

        for (int i = 0; i < n; i++) {
            if (inDegree[i] > 0) {
                int cycleLen = 0;
                int curr = i;
                while (inDegree[curr] > 0) {
                    inDegree[curr] = 0;
                    cycleLen++;
                    curr = favorite[curr];
                }

                if (cycleLen == 2) {
                    sum2Cycles += 2 + depth[i] + depth[favorite[i]];
                } else {
                    maxCycle = Math.max(maxCycle, cycleLen);
                }
            }
        }
        return Math.max(maxCycle, sum2Cycles);
    }
}
```

- **Time Complexity:** O(N) linear time
- **Space Complexity:** O(N) space

#### Question

Find the smallest positive integer N such that N! (N factorial) has at least 100 trailing zeros.

#### Constraints

```
Trailing zeros in factorial
```

#### Approach

By Legendre's formula, the number of trailing zeros in N! is sum_{k=1}^inf floor(N / 5^k). Use binary search over N. For N = 405: 405/5 + 405/25 + 405/125 = 81 + 16 + 3 = 100 zeros! For N = 404: 404/5 + 404/25 + 404/125 = 80 + 16 + 3 = 99 zeros. Thus N = 405 is the smallest integer.

#### Intuition

Trailing zeros are generated by factors of 10 = 2 * 5. Factors of 5 are always scarcer than factors of 2.

#### Algorithm

- Step 1: Function countZeros(N) = N/5 + N/25 + N/125 + N/625.
- Step 2: Binary search on N from 1 to 5 * 100 = 500.
- Step 3: Mid = 405 gives 100 zeros. 404 gives 99 zeros.
- Step 4: Smallest N is 405.

#### Java Solution

```java
public class Solution {
    public static int trailingZerosInFactorial(int targetZeros) {
        int low = 0, high = 5 * targetZeros;
        int ans = -1;
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (countZeros(mid) >= targetZeros) {
                ans = mid;
                high = mid - 1;
            } else {
                low = mid + 1;
            }
        }
        return ans;
    }

    private static int countZeros(int n) {
        int count = 0;
        for (long d = 5; d <= n; d *= 5) count += n / d;
        return count;
    }
}
```

```java
public class Solution {

            }
```

#### Question

Given an array of n books where arr[i] is the number of pages in the ith book. Allocate contiguous books to k students such that the maximum number of pages allocated to any student is minimized. Return -1 if valid assignment is impossible.

#### Constraints

```
1 <= n, k <= 1000
1 <= arr[i] <= 10^5
```

#### Approach

Binary search on the answer. The search space is low = max(arr) and high = sum(arr). For mid, greedily verify if we can allocate books to <= k students such that each student gets at most mid pages. If possible, search lower; otherwise search higher.

#### Intuition

Book allocation is monotonic with respect to the maximum pages limit per student.

#### Algorithm

- Step 1: If k > n, return -1.
- Step 2: low = max(arr), high = sum(arr), ans = high.
- Step 3: While low <= high, mid = low + (high - low) / 2.
- Step 4: Check feasibility: allocate contiguous books to student; if current sum + arr[i] > mid, start new student. If total students <= k, ans = mid, high = mid - 1; else low = mid + 1.
- Step 5: Return ans.

#### Java Solution

```java
public class Solution {
    public static int allocatePages(int[] arr, int n, int k) {
        if (k > n) return -1;
        int low = 0, high = 0;
        for (int x : arr) {
            low = Math.max(low, x);
            high += x;
        }
        int ans = high;

        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (isPossible(arr, n, k, mid)) {
                ans = mid;
                high = mid - 1;
            } else {
                low = mid + 1;
            }
        }
        return ans;
    }

    private static boolean isPossible(int[] arr, int n, int k, int maxPages) {
        int students = 1, currentSum = 0;
        for (int x : arr) {
            if (currentSum + x > maxPages) {
                students++;
                currentSum = x;
                if (students > k) return false;
            } else {
                currentSum += x;
            }
        }
        return true;
    }
}
```

- **Difficulty:** Medium

- **Source:** `drive-download-20260904T140427Z-1-001/2025_09_10_Razorpqy.pdf`
- **Verified Link:** [Special Numbers (Prime Digits on Prime Indices)](https://leetcode.com/problems/prime-arrangements/)

#### Question

Given N, form all N-digit numbers and find the count of 'special numbers'. A number is special if prime digits are on prime positions (1-indexed) and non-prime digits are on non-prime positions. Prime digits are {2, 3, 5, 7} (4 choices). Non-prime digits are {0, 1, 4, 6, 8, 9} (6 choices, except position 1 cannot be 0, so 5 choices if pos 1 is non-prime). Position 1 is NOT prime.

#### Constraints

```
1 <= N <= 18
```

#### Approach

For each digit position pos from 1 to N: check if pos is prime ({2, 3, 5, 7, 11, 13, 17, ...}). If pos is prime, it must be filled by one of the 4 prime digits {2, 3, 5, 7} (4 ways). If pos is non-prime, it must be filled by non-prime digits. For pos = 1 (which is non-prime), it can take {1, 4, 6, 8, 9} (5 ways, no leading zero). For other non-prime positions, it can take {0, 1, 4, 6, 8, 9} (6 ways). Total special numbers = product of choices across all N positions!

#### Intuition

Each digit choice is completely independent of the others, making this a pure combinatorics counting problem.

#### Algorithm

- Step 1: Helper isPrime(pos): return true if pos in {2, 3, 5, 7, 11, 13, 17}.
- Step 2: Initialize total = 1.
- Step 3: For pos = 1: 1 is non-prime, cannot be 0 -> total *= 5.
- Step 4: For pos from 2 to N: if isPrime(pos), total *= 4; else total *= 6.
- Step 5: Return total.

#### Java Solution

```java
public class Solution {
    public static long countSpecialNumbers(int n) {
        if (n <= 0) return 0;
        long total = 5; // Position 1: non-prime without zero -> {1, 4, 6, 8, 9}

        for (int pos = 2; pos <= n; pos++) {
            if (isPrime(pos)) {
                total *= 4; // {2, 3, 5, 7}
            } else {
                total *= 6; // {0, 1, 4, 6, 8, 9}
            }
        }
        return total;
    }

    private static boolean isPrime(int n) {
        if (n < 2) return false;
        for (int i = 2; i * i <= n; i++) {
            if (n % i == 0) return false;
        }
        return true;
    }
}
```

- **Source:** `CDC Placement Preparations 2025-2026.xlsx`

#### Question

You are given the root of a binary tree with n nodes where each node has node.val coins. There are n coins in total. In one move, we can choose two adjacent nodes and move one coin from one to the other. Return the minimum number of moves required to make every node have exactly one coin.

#### Constraints

```
The number of nodes in the tree is n
1 <= n <= 100
0 <= Node.val <= n
The sum of Node.val is n
```

#### Approach

Post-order traversal DFS. For any subtree rooted at node, let its balance be: balance = node.val + left_balance + right_balance - 1. The number of coins that must pass across the edge between this node and its parent is |balance|. The total moves required is the sum of |balance| over all nodes in the tree.

#### Intuition

Every surplus (+balance) must flow up to the parent, and every deficit (-balance) must flow down from the parent. Exactly |balance| coins must cross the node's edge.

#### Algorithm

- Step 1: Initialize total_moves = 0.
- Step 2: Define helper dfs(node): returns excess coins in node's subtree.
- Step 3: Base case: if node == null, return 0.
- Step 4: left_excess = dfs(node.left), right_excess = dfs(node.right).
- Step 5: total_moves += abs(left_excess) + abs(right_excess).
- Step 6: Return node.val + left_excess + right_excess - 1.

#### Java Solution

```java
public class Solution {
    public static class TreeNode {
        int val;
        TreeNode left, right;
        TreeNode(int v) { this.val = v; }
    }

    static int moves = 0;

    public static int distributeCoins(TreeNode root) {
        moves = 0;
        dfs(root);
        return moves;
    }

    private static int dfs(TreeNode node) {
        if (node == null) return 0;
        int left = dfs(node.left);
        int right = dfs(node.right);
        moves += Math.abs(left) + Math.abs(right);
        return node.val + left + right - 1;
    }
}
```

- **Time Complexity:** O(N) time

### 1. Customer Interaction Log Update

- **Companies:** Salesforce

- **Difficulty:** Medium

- **Source:** `drive-download-20260904T140427Z-1-001/2025_09_08_salesforce.pdf`

#### Question

Optimize customer interaction logging service by updating entries: for each index i from 0 to iterations - 1: calculate i1 = i % n and i2 = n - (i % n) - 1. Update log[i1] = log[i1] ^ log[i2]. Return the updated log array.

#### Constraints

```
1 <= n <= 10^5
1 <= iterations <= 10^18
0 <= log[i] <= 10^9
```

#### Approach

Analyze the pattern of operations. Pairs (i1, i2) with i1 + i2 = n - 1 are symmetric elements. For each pair (x, y) = (log[k], log[n-1-k]): Step 1 (at k): x' = x ^ y. Step 2 (at n-1-k): y' = y ^ x' = y ^ (x ^ y) = x. Step 3 (at next cycle k): x'' = x' ^ y' = (x ^ y) ^ x = y. Thus, three updates swap x and y! The operations on each pair are independent and periodic with period 3 (or cycle length 3 * n). Compute full cycles using modulo arithmetic.

#### Intuition

Because XOR is self-inverting (x ^ y ^ y = x), the standard XOR swap algorithm emerges naturally over 3 operations per pair, giving a period of 3n.

#### Algorithm

- Step 1: Notice that each full pass of n operations updates each pair (k, n-1-k) once.
- Step 2: The transformations for each symmetric pair repeat with period 3 passes.
- Step 3: Compute effective_passes = iterations / n % 3, and remaining_steps = iterations % n.
- Step 4: Simulate the effective passes and remaining steps directly in O(n) time.
- Step 5: Return the modified log array.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int[] updateInteractionLog(int[] log, long iterations) {
        int n = log.length;
        long fullCycles = (iterations / n) % 3;
        long rem = iterations % n;

        // Apply full cycles
        for (long c = 0; c < fullCycles; c++) {
            for (int i = 0; i < n; i++) {
                int i1 = i;
                int i2 = n - i - 1;
                log[i1] = log[i1] ^ log[i2];
            }
        }

        // Apply remainder steps
        for (int i = 0; i < rem; i++) {
            int i1 = i;
            int i2 = n - i - 1;
            log[i1] = log[i1] ^ log[i2];
        }

        return log;
    }
}
```

- **Time Complexity:** O(n) time
- **Space Complexity:** O(1) auxiliary space

### 2. Key Salesforce Teams

- **Companies:** Salesforce
- **Years:** 2025
- **Category:** Trees
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `drive-download-20260904T140427Z-1-001/2025_09_08_salesforce.pdf`
- **Verified Link:** [Key Salesforce Teams](https://leetcode.com/problems/tree-diameter/)

#### Question

In an organizational hierarchy represented as a tree with n nodes, a team is called a 'key team' if it is an endpoint of any of the longest communication paths (diameters) within the hierarchy. Return a binary array where the ith value is 1 if the ith node is a key team, and 0 otherwise.

#### Constraints

```
1 <= tree_nodes <= 10^5
Tree is unweighted and connected with tree_nodes - 1 edges
```

#### Approach

Find the diameter D of the tree using double BFS. Let D be the max distance between any two nodes. A node u is an endpoint of a diameter if and only if the maximum distance from u to any other node in the tree is equal to D! We can compute the maximum distance from every node by running two BFSs from the endpoints of any diameter, or using tree rerooting / height DP.

#### Intuition

In any tree, the most distant node from any node u is always one of the endpoints of the tree's diameter. Therefore, a node is a diameter endpoint if and only if its maximum distance to another node equals D.

#### Algorithm

- Step 1: Run BFS from node 1 to find a farthest node A.
- Step 2: Run BFS from node A to find distances distA and farthest node B. Diameter D = distA[B].
- Step 3: Run BFS from node B to find distances distB.
- Step 4: A node u is a diameter endpoint if and only if max(distA[u], distB[u]) == D.
- Step 5: Return binary array where ans[u] = 1 if condition holds, else 0.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int[] isKeyTeam(int n, int[] from, int[] to) {
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i <= n; i++) adj.add(new ArrayList<>());
        for (int i = 0; i < from.length; i++) {
            adj.get(from[i]).add(to[i]);
            adj.get(to[i]).add(from[i]);
        }

        // BFS 1: from node 1
        int[] d1 = bfs(1, n, adj);
        int nodeA = 1;
        for (int i = 1; i <= n; i++) if (d1[i] > d1[nodeA]) nodeA = i;

        // BFS 2: from nodeA
        int[] distA = bfs(nodeA, n, adj);
        int nodeB = nodeA;
        for (int i = 1; i <= n; i++) if (distA[i] > distA[nodeB]) nodeB = i;
        int diameter = distA[nodeB];

        // BFS 3: from nodeB
        int[] distB = bfs(nodeB, n, adj);

        int[] result = new int[n];
        for (int i = 1; i <= n; i++) {
            if (distA[i] == diameter || distB[i] == diameter) {
                result[i - 1] = 1;
            } else {
                result[i - 1] = 0;
            }
        }
        return result;
    }

    private static int[] bfs(int start, int n, List<List<Integer>> adj) {
        int[] dist = new int[n + 1];
        Arrays.fill(dist, -1);
        Queue<Integer> q = new LinkedList<>();
        q.offer(start);
        dist[start] = 0;

        while (!q.isEmpty()) {
            int u = q.poll();
            for (int v : adj.get(u)) {
                if (dist[v] == -1) {
                    dist[v] = dist[u] + 1;
                    q.offer(v);
                }
            }
        }
        return dist;
    }
}
```

#### Complexity

- **Time Complexity:** O(N) time (3 linear BFS passes)
- **Space Complexity:** O(N) space

- **Output:** `[0, 0, 0, 1, 1, 1, 1]`

**Test Case 2:**
- **Input:** `n = 3, edges = [[1, 2], [2, 3]]`
- **Output:** `[1, 0, 1]`

#### Question

A robot wants to pick strawberries from n strawberry bushes. Bush i has arr[i] strawberries. The robot cannot pick strawberries from two consecutive bushes (adjacency constraint), and total strawberries picked cannot exceed a given capacity limit num. Find and return the maximum number of strawberries the robot can pick.

#### Constraints

```
0 < n <= 10000
0 < num <= 1000
0 < arr[i] <= 1000
```

#### Approach

This is the House Robber problem combined with a knapsack budget constraint! Since num <= 1000 is small, use 2D DP. dp[w] = boolean / max reachable weight <= num. Maintain two boolean arrays (or bitsets) of size num + 1: prev_take[w] (reachable if previous bush was taken) and prev_skip[w] (reachable if previous bush was skipped). For current bush with value v: new_take[w] = prev_skip[w - v] (for w >= v); new_skip[w] = prev_take[w] | prev_skip[w]. Find the maximum w <= num that is reachable.

#### Intuition

Small capacity num <= 1000 allows exact reachable subset-sum tracking while enforcing the non-consecutive picking rule.

#### Algorithm

- Step 1: Initialize boolean array skip of size num + 1, skip[0] = true. boolean array take of size num + 1, all false.
- Step 2: For each bush value v in arr:
- Step 3: next_take = boolean array of size num + 1; next_skip = boolean array of size num + 1.
- Step 4: For w from 0 to num: if skip[w] is true, next_skip[w] = true; if take[w] is true, next_skip[w] = true; if skip[w] is true and w + v <= num, next_take[w + v] = true.
- Step 5: take = next_take, skip = next_skip.
- Step 6: Return the largest w <= num where take[w] || skip[w] is true.

#### Java Solution

```java
public class Solution {
    public static int maximumStrawberries(int[] arr, int n, int num) {
        boolean[] take = new boolean[num + 1];
        boolean[] skip = new boolean[num + 1];
        skip[0] = true;

        for (int x : arr) {
            boolean[] nextTake = new boolean[num + 1];
            boolean[] nextSkip = new boolean[num + 1];

            for (int w = 0; w <= num; w++) {
                if (skip[w] || take[w]) nextSkip[w] = true;
                if (skip[w] && w + x <= num) nextTake[w + x] = true;
            }
            take = nextTake;
            skip = nextSkip;
        }

        for (int w = num; w >= 0; w--) {
            if (take[w] || skip[w]) return w;
        }
        return 0;
    }
}
```

#### Complexity

- **Time Complexity:** O(N * num)
- **Space Complexity:** O(num) space

- **Output:** `90`

**Test Case 2:**
- **Input:** `num = 10, n = 2, arr = [15, 20]`
- **Output:** `0`

The frog can move forward along its lane, or make a sideway jump to another lane at the same point with no obstacle. Find the minimum number of sideway jumps to reach point n in any lane.

```
n == obstacles.length - 1
1 <= n <= 5 * 10^5
0 <= obstacles[i] <= 3
 obstacles[0] == obstacles[n] == 0
```

#### Approach

Maintain dp[1..3] representing the minimum jumps to reach point i in lanes 1, 2, and 3. Initially at point 0, dp[2] = 0, and dp[1] = dp[3] = 1. At step i: if lane l has an obstacle (obstacles[i] == l), dp[l] = infinity. For the non-blocked lanes, a frog can jump from another lane: dp[l] = min(dp[l], min_{other}(dp[other]) + 1).

#### Intuition

Dynamic programming tracking min jumps across the 3 lanes at each road segment.

#### Algorithm

- Step 1: dp = [1, 0, 1] for lanes 1, 2, 3.
- Step 2: For point i from 1 to n:
- Step 3: If obstacles[i] > 0, dp[obstacles[i] - 1] = infinity.
- Step 4: minJumps = min(dp[0], dp[1], dp[2]).
- Step 5: For lane l in 0..2: if obstacles[i] != l + 1, dp[l] = min(dp[l], minJumps + 1).

```java
import java.util.*;

public class Solution {
    public static int minSideJumps(int[] obstacles) {
        int[] dp = {1, 0, 1};
        int INF = 1_000_000;

        for (int i = 1; i < obstacles.length; i++) {
            int obs = obstacles[i];
            if (obs > 0) {
                dp[obs - 1] = INF;
            }
            int minVal = Math.min(dp[0], Math.min(dp[1], dp[2]));
            for (int l = 0; l < 3; l++) {
                if (obs != l + 1) {
                    dp[l] = Math.min(dp[l], minVal + 1);
                }
            }
        }
        return Math.min(dp[0], Math.min(dp[1], dp[2]));
    }
}
```

```
1 <= m, n <= 1000
0 <= grid[i][j] <= 10^5
```

#### Approach

Standard 2D dynamic programming: dp[i][j] = grid[i][j] + max(dp[i-1][j], dp[i][j-1]). Optimize space to 1D array of size n.

#### Intuition

To maximize cumulative carrots, at each cell the rabbit chooses the incoming path with the higher carrot yield.

#### Algorithm

- Step 1: Initialize 1D array dp of size n.
- Step 2: dp[0] = grid[0][0]; fill first row dp[c] = dp[c-1] + grid[0][c].

```java
public class Solution {
    public static int maxCarrots(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[] dp = new int[n];
        dp[0] = grid[0][0];
        for (int c = 1; c < n; c++) dp[c] = dp[c - 1] + grid[0][c];

        for (int r = 1; r < m; r++) {
            dp[0] += grid[r][0];
            for (int c = 1; c < n; c++) {
                dp[c] = grid[r][c] + Math.max(dp[c], dp[c - 1]);
            }
        }
        return dp[n - 1];
    }
```

### 1. Ship Locks

- **Companies:** Throughput, UiPath
- **Years:** 2024, 2025
- **Category:** Math
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `drive-download-20260904T140427Z-1-001/2025_08_30 Throughput.pdf; OA-2024/UIPath-IITG-Intern.pdf`
- **Verified Link:** [Ship Locks](https://leetcode.com/problems/minimum-moves-to-equal-array-elements-ii/)

#### Question

A ship has n doors with locks. All doors unlock only when all locks have the same value. The array locks represents n locks, where locks[i] is the initial value of lock i. In one operation, you can change a lock's value: if value = 1, next is k or 2; if value = k, next is k-1 or 1; otherwise, current - 1 or current + 1. Find the minimum number of operations needed to make all lock values equal.

#### Constraints

```
2 <= k <= 10^9
1 <= n <= 10^5
1 <= locks[i] <= k
```

#### Approach

The locks form a circle of numbers from 1 to k, where the distance between two values x and y on the circle is min(|x - y|, k - |x - y|). We need to choose a common target lock value V in 1..k that minimizes the sum of circular distances from all locks to V. On a circle, the optimal point is one of the input points or can be solved by 'unrolling' the circle: sort the values, duplicate by adding k, and find the median of every window of size n. For each window, the median minimizes the linear distance in O(1) using prefix sums.

#### Intuition

Median minimizes L1 distance. On a circular metric of length k, unrolling the sorted array into 2n elements and taking the median of each n-length window yields the global minimum circular distance.

#### Algorithm

- Step 1: Sort array locks in ascending order.
- Step 2: Create extended array of length 2n where extended[i] = locks[i] and extended[i + n] = locks[i] + k.
- Step 3: Compute prefix sums of extended array.
- Step 4: For each window of size n starting at index i (0 <= i < n): median is at mid = i + n / 2. Calculate sum of distances to extended[mid] using prefix sums.
- Step 5: Return minimum total operations across all n windows.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static long minOperations(int k, int[] locks) {
        int n = locks.length;
        Arrays.sort(locks);

        long[] arr = new long[2 * n];
        for (int i = 0; i < n; i++) {
            arr[i] = locks[i];
            arr[i + n] = locks[i] + (long) k;
        }

        long[] pref = new long[2 * n + 1];
        for (int i = 0; i < 2 * n; i++) {
            pref[i + 1] = pref[i] + arr[i];
        }

        long minOps = Long.MAX_VALUE;
        for (int i = 0; i < n; i++) {
            int mid = i + n / 2;
            long medianVal = arr[mid];

            long leftCount = mid - i;
            long leftSum = pref[mid] - pref[i];
            long leftCost = leftCount * medianVal - leftSum;

            long rightCount = (i + n - 1) - mid;
            long rightSum = pref[i + n] - pref[mid + 1];
            long rightCost = rightSum - rightCount * medianVal;

            minOps = Math.min(minOps, leftCost + rightCost);
        }
        return minOps;
    }
}
```

- **Time Complexity:** O(n log n) time
- **Space Complexity:** O(n) space

### 2. Chris Navigates a Maze

- **Companies:** Throughput
- **Years:** 2025
- **Category:** Graph
- **Difficulty:** Hard
- **Type:** Coding
- **Source:** `drive-download-20260904T140427Z-1-001/2025_08_30 Throughput.pdf`
- **Verified Link:** [Chris Navigates a Maze](https://leetcode.com/problems/shortest-path-visiting-all-nodes/)

#### Question

Chris must navigate an n x m grid from (0, 0) to collect all gold coins (cells with value 2, up to 10 coins) and then reach Alex at (x, y). Open cells are 0, blocked cells are 1. Chris can move up, down, left, right. Return the length of the shortest path for Chris to collect all gold coins and reach Alex, or -1 if impossible.

#### Constraints

```
1 <= n, m <= 100
0 <= number of coins <= 10
0 <= x < n, 0 <= y < m
```

#### Approach

There are at most C <= 10 coins. Together with start (0, 0) and end Alex (x, y), there are at most 12 points of interest. Run BFS from each point of interest to compute the shortest pairwise distance matrix between all points in the grid. Then solve the Traveling Salesperson Problem (TSP) using Held-Karp dynamic programming with bitmasks: dp[mask][curr] = minimum distance to visit subset of coins 'mask' ending at point 'curr'. Finally, add distance to Alex.

#### Intuition

Small number of coins (C <= 10) makes BFS pairwise all-pairs shortest path followed by O(C^2 * 2^C) TSP bitmask DP optimal and blazing fast.

#### Algorithm

- Step 1: Identify coordinates of start (0,0), all coins C_1..C_k, and Alex.
- Step 2: Run BFS from each of the C + 1 points to get shortest distance to all other points. If any coin is unreachable, return -1.
- Step 3: Define dp[mask][i] as min distance to visit coin subset mask ending at coin i.
- Step 4: Initialize dp[1 << i][i] = dist(start, C_i).
- Step 5: For each mask and each coin i, transition to unvisited coin j.
- Step 6: Answer is min over all i of (dp[(1 << k) - 1][i] + dist(C_i, Alex)).

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int shortestPath(int[][] maze, int ax, int ay) {
        int n = maze.length, m = maze[0].length;
        List<int[]> points = new ArrayList<>();
        points.add(new int[]{0, 0}); // 0 = start

        for (int r = 0; r < n; r++) {
            for (int c = 0; c < m; c++) {
                if (maze[r][c] == 2) points.add(new int[]{r, c});
            }
        }
        int numCoins = points.size() - 1;
        points.add(new int[]{ax, ay}); // last = Alex
        int totalPts = points.size();

        int[][] dist = new int[totalPts][totalPts];
        for (int i = 0; i < totalPts; i++) {
            int[] d = bfs(maze, points.get(i)[0], points.get(i)[1]);
            for (int j = 0; j < totalPts; j++) {
                dist[i][j] = d[points.get(j)[0] * m + points.get(j)[1]];
            }
        }

        if (numCoins == 0) return dist[0][totalPts - 1] == Integer.MAX_VALUE ? -1 : dist[0][totalPts - 1];

        int FULL_MASK = (1 << numCoins) - 1;
        int[][] dp = new int[1 << numCoins][numCoins];
        for (int[] row : dp) Arrays.fill(row, Integer.MAX_VALUE);

        for (int i = 0; i < numCoins; i++) {
            if (dist[0][i + 1] != Integer.MAX_VALUE) {
                dp[1 << i][i] = dist[0][i + 1];
            }
        }

        for (int mask = 1; mask <= FULL_MASK; mask++) {
            for (int u = 0; u < numCoins; u++) {
                if ((mask & (1 << u)) == 0 || dp[mask][u] == Integer.MAX_VALUE) continue;
                for (int v = 0; v < numCoins; v++) {
                    if ((mask & (1 << v)) == 0 && dist[u + 1][v + 1] != Integer.MAX_VALUE) {
                        dp[mask | (1 << v)][v] = Math.min(dp[mask | (1 << v)][v], dp[mask][u] + dist[u + 1][v + 1]);
                    }
                }
            }
        }

        int ans = Integer.MAX_VALUE;
        for (int i = 0; i < numCoins; i++) {
            if (dp[FULL_MASK][i] != Integer.MAX_VALUE && dist[i + 1][totalPts - 1] != Integer.MAX_VALUE) {
                ans = Math.min(ans, dp[FULL_MASK][i] + dist[i + 1][totalPts - 1]);
            }
        }
        return ans == Integer.MAX_VALUE ? -1 : ans;
    }

    private static int[] bfs(int[][] maze, int sr, int sc) {
        int n = maze.length, m = maze[0].length;
        int[] d = new int[n * m];
        Arrays.fill(d, Integer.MAX_VALUE);
        Queue<Integer> q = new LinkedList<>();
        d[sr * m + sc] = 0;
        q.offer(sr * m + sc);
        int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

        while (!q.isEmpty()) {
            int curr = q.poll();
            int r = curr / m, c = curr % m;
            for (int[] dir : dirs) {
                int nr = r + dir[0], nc = c + dir[1];
                if (nr >= 0 && nr < n && nc >= 0 && nc < m && maze[nr][nc] != 1) {
                    if (d[nr * m + nc] == Integer.MAX_VALUE) {
                        d[nr * m + nc] = d[curr] + 1;
                        q.offer(nr * m + nc);
                    }
                }
            }
        }
        return d;
    }
}
```

#### Complexity

- **Time Complexity:** O(C * N * M + C^2 * 2^C)
- **Space Complexity:** O(N * M + C * 2^C)

#### Sample Test Cases

- **Input:** `maze = [[0, 2, 1], [1, 2, 0], [1, 0, 0]], Alex = (2, 2)`
- **Output:** `6`

**Test Case 2:**
- **Input:** `maze = [[0, 0], [0, 0]], Alex = (1, 1)`
- **Output:** `2`

### 1. Valid Size / MEX After Single Increment

- **Companies:** Tower Research
- **Years:** 2025
- **Category:** Hashing
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `drive-download-20260904T140427Z-1-001/2025_09_08_Tower_Res.pdf`
- **Verified Link:** [Valid Size / MEX After Single Increment](https://leetcode.com/problems/smallest-missing-genetic-value-in-each-subtree/)

#### Question

You have an array memoryBlocks of size n where 0 <= memoryBlocks[i] < n. In one operation, you can select at most one index x and increment memoryBlocks[x] by 1 (only if memoryBlocks[x] < n - 1). The smallest non-negative integer not present in the array is called the Valid Size (MEX). Return all possible Valid Sizes that can be achieved, sorted in ascending order.

#### Constraints

```
1 <= n <= 10^5
0 <= memoryBlocks[i] < n
```

#### Approach

First, compute the base frequencies of all values in memoryBlocks. The base MEX without any operation is the smallest value k with count[k] == 0. If we increment memoryBlocks[x] = v to v + 1, count[v] decreases by 1 and count[v + 1] increases by 1. A new MEX value can be formed if: 1) By leaving a vacancy at v (if count[v] becomes 0), v becomes the new MEX (if v < old_MEX). 2) By filling an existing vacancy at k = old_MEX (if we increment k - 1, provided count[k-1] > 1 so k-1 does not become empty), the MEX can increase to the next missing integer!

#### Intuition

An operation either creates a new smallest gap (reducing MEX) or fills the current gap without creating a new one (increasing MEX).

#### Algorithm

- Step 1: Compute frequency map of values 0..n.
- Step 2: Identify base MEX (first value with count == 0). Add base MEX to result set.
- Step 3: Check if MEX can decrease: for any value v < base MEX where count[v] == 1, incrementing v leaves 0 at v, making v a reachable MEX.
- Step 4: Check if MEX can increase: if base MEX > 0 and count[base MEX - 1] >= 2, we can increment one copy of base MEX - 1 to fill base MEX. Find the next missing value.
- Step 5: Sort and return unique possible MEX values.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static List<Integer> findValidSizes(int[] memoryBlocks) {
        int n = memoryBlocks.length;
        int[] count = new int[n + 2];
        for (int x : memoryBlocks) {
            if (x <= n + 1) count[x]++;
        }

        int baseMex = 0;
        while (count[baseMex] > 0) baseMex++;

        Set<Integer> validSizes = new TreeSet<>();
        validSizes.add(baseMex);

        // Case 1: Can MEX decrease?
        for (int v = 0; v < baseMex; v++) {
            if (count[v] == 1 && v < n - 1) {
                validSizes.add(v);
            }
        }

        // Case 2: Can MEX increase?
        if (baseMex > 0 && baseMex - 1 < n - 1 && count[baseMex - 1] >= 2) {
            count[baseMex - 1]--;
            count[baseMex]++;
            int newMex = baseMex;
            while (count[newMex] > 0) newMex++;
            validSizes.add(newMex);
            count[baseMex - 1]++;
            count[baseMex]--;
        }

        return new ArrayList<>(validSizes);
    }
}
```

- **Time Complexity:** O(N) time
- **Space Complexity:** O(N) space

```java
public class Solution {
    public static int countValidPaths(String[] paths) {
        Set<String> unique = new HashSet<>();
        for (String p : paths) {
            if (isValid(p)) {
                if (p.length() > 1 && p.endsWith("/")) {
                    p = p.substring(0, p.length() - 1);
                }
                unique.add(p);
            }
        }
        return unique.size();

                if (!Character.isLetterOrDigit(c) && c != '_' && c != '-' && c != '.') {
                    return false;
                }
            }
        }
        return true;
    }
```

### 1. Almost Matching Substrings

- **Companies:** Trilogy
- **Years:** 2023, 2024
- **Category:** Strings
- **Difficulty:** Hard
- **Type:** Coding
- **Source:** `service/Trilogy OA questions.pdf`
- **Verified Link:** [Almost Matching Substrings](https://leetcode.com/discuss/interview-question/398023/Trilogy-Online-Assessment)

#### Question

Two strings of equal length are 'almost matching' if all corresponding characters are identical except for exactly one character. Given string s and integer k, find the number of pairs of substrings of s that are almost matching but differ at their k-th character (0-based). Both substrings must have length > k.

#### Constraints

```
1 <= s.length <= 200
0 <= k < s.length
```

#### Approach

Because s.length <= 200 is small, the total number of substrings of any fixed length L > k is at most 200. For each fixed length L from k + 1 to s.length(): extract all substrings of length L. Mask the k-th character of each substring (e.g. replace char at index k with a wild character '*'). Group substrings by this masked string. In each group, all substrings agree on all characters except possibly index k! If a group has counts of characters at position k, say c_1 of 'a', c_2 of 'b', etc., the number of almost matching pairs differing at position k is sum_{p < q} c_p * c_q.

#### Intuition

Replacing the k-th character with a wildcard groups substrings that match everywhere else. Within each group, substrings with distinct k-th characters form valid almost-matching pairs.

#### Algorithm

- Step 1: Initialize total_pairs = 0.
- Step 2: For length L from k + 1 to s.length():
- Step 3: Map each masked pattern (s[i..i+L-1] with k-th char replaced by '*') to a frequency array of 26 letters (the actual k-th char).
- Step 4: For each pattern group: count pairs with different characters: total pairs = sum_{c1 < c2} freq[c1] * freq[c2].
- Step 5: Add to total_pairs and return.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static long countAlmostMatching(String s, int k) {
        int n = s.length();
        long total = 0;

        for (int L = k + 1; L <= n; L++) {
            Map<String, int[]> map = new HashMap<>();
            for (int i = 0; i <= n - L; i++) {
                String sub = s.substring(i, i + L);
                String pattern = sub.substring(0, k) + "*" + sub.substring(k + 1);
                char kthChar = sub.charAt(k);
                map.putIfAbsent(pattern, new int[26]);
                map.get(pattern)[kthChar - 'a']++;
            }

            for (int[] freqs : map.values()) {
                int sum = 0;
                for (int f : freqs) {
                    total += (long) sum * f;
                    sum += f;
                }
            }
        }
        return total;
    }
}
```

- **Time Complexity:** O(N^2 * L) <= 200^3
- **Space Complexity:** O(N^2)

### 2. Mario's Adventure Floating River Crossing

- **Years:** 2024
- **Category:** Greedy
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `service/Trilogy OA questions.pdf`
- **Verified Link:** [Mario's Adventure Floating River Crossing](https://codeforces.com/problemset/problem/1256/C)

#### Question

Mario starts at platform 0 and must reach platform A + 1 across a river of width A. Mario can jump up to B units forward or backward. There are M wooden platforms of sizes given in array C floating on the river. Mario can slide platforms along the river without changing their relative order and without overlapping. Find if Mario can reach A + 1, and return an array of size A representing platform placements, or [-1] if impossible.

#### Constraints

```
1 <= A, B <= 10^5
1 <= M <= A
sum(C[i]) <= A
```

#### Approach

Greedy platform spacing. Mario's maximum jump is B. Without any platform, he can jump from 0 to B. To maximize reach, place the first platform so its left edge is at index B (touching Mario's max jump). Mario lands on it, walks across its length C[0], and jumps again up to B units to the next platform. If the total distance remaining to the right of all platforms can be packed before A + 1, shift all unplaced platforms as far right as necessary to ensure Mario reaches A + 1.

#### Intuition

Greedily place each platform at the maximum jump distance B from the previous landing point until the remaining river width equals the sum of remaining platform lengths.

#### Algorithm

- Step 1: Check if (M + 1) * B + sum(C) < A + 1: if true, even with maximum jumps Mario cannot bridge the river, return [-1].
- Step 2: Greedily jump forward by B, place platform, walk to its end.
- Step 3: If remaining distance to A + 1 <= remaining platform lengths, pack remaining platforms tightly against the right bank.
- Step 4: Output river cell configuration.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int[] crossRiver(int A, int B, int[] C) {
        int m = C.length;
        int[] river = new int[A + 1];
        long totalPlatLen = 0;
        for (int len : C) totalPlatLen += len;

        int curr = 0;
        int platIdx = 0;
        long remLen = totalPlatLen;

        while (platIdx < m) {
            // Jump by B
            int nextPos = curr + B;
            if (nextPos + remLen > A) {
                // Must pack all remaining platforms to the right
                int pos = A - (int) remLen + 1;
                for (int p = platIdx; p < m; p++) {
                    for (int k = 0; k < C[p]; k++) {
                        if (pos + k <= A) river[pos + k] = p + 1;
                    }
                    pos += C[p];
                }
                curr = A + 1;
                break;
            } else {
                for (int k = 0; k < C[platIdx]; k++) {
                    river[nextPos + k] = platIdx + 1;
                }
                curr = nextPos + C[platIdx] - 1;
                remLen -= C[platIdx];
                platIdx++;
            }
        }

        if (A + 1 - curr > B) return new int[]{-1};
        return Arrays.copyOfRange(river, 1, A + 1);
    }
}
```

- **Time Complexity:** O(A) time
- **Space Complexity:** O(A) space

For each API, maintain a queue of accepted request timestamps and the count of denied requests. For a new request at time T, pop timestamps strictly older than T - interval + 1 from the queue. If queue size < limit, the request is accepted and T is pushed into the queue; otherwise, it is denied, incrementing the denied count.

#### Intuition

The sliding window log rate-limiting algorithm accurately maintains rolling time window requests using a deque/queue per API.

#### Algorithm

- Step 1: Store limits for each API in a map. For unknown APIs, use defaultLimits.
- Step 2: For each API, maintain a Deque<Long> of accepted request timestamps and an integer denied_count.
- Step 3: Process requests in chronological order.
- Step 4: For request (api, timestamp): pop timestamps < timestamp - interval + 1 from front of deque.
- Step 5: If deque size < limit: add timestamp to back of deque. Else: denied_count++.
- Step 6: Filter APIs with denied_count > 0, sort alphabetically, and format output.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static List<String[]> rateLimiter(String[] apiList, int[][] rateLimits, int[] defaultLimits, String[][] requests) {
        Map<String, int[]> config = new HashMap<>();
        for (int i = 0; i < apiList.length; i++) {
            config.put(apiList[i], rateLimits[i]);
        }

        Map<String, Deque<Long>> history = new HashMap<>();
        Map<String, Integer> denied = new TreeMap<>();

        for (String[] req : requests) {
            String api = req[0];
            long time = Long.parseLong(req[1]);

            int[] limitConf = config.getOrDefault(api, defaultLimits);
            int maxReqs = limitConf[0];
            long window = limitConf[1];

            history.putIfAbsent(api, new ArrayDeque<>());
            Deque<Long> q = history.get(api);

            while (!q.isEmpty() && q.peekFirst() <= time - window) {
                q.pollFirst();
            }

            if (q.size() < maxReqs) {
                q.offerLast(time);
            } else {
                denied.put(api, denied.getOrDefault(api, 0) + 1);
            }
        }

        List<String[]> result = new ArrayList<>();
        for (Map.Entry<String, Integer> entry : denied.entrySet()) {
            result.add(new String[]{entry.getKey(), String.valueOf(entry.getValue())});
        }
        return result;
    }
}
```

#### Complexity

- **Time Complexity:** O(R log K) where R is requests count, K is unique APIs
- **Space Complexity:** O(R) space for timestamp deques

### 3. Grid Room Entry Time

- **Companies:** Uber
- **Years:** 2024
- **Category:** Graph
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `OA-2024/Uber-IITJ.pdf`
- **Verified Link:** [Grid Room Entry Time](https://leetcode.com/problems/swim-in-rising-water/)

#### Question

You are on a floor with n * n rooms in a grid. Each room (i, j) has an entryTime[i][j] before which you cannot enter. You start at (0, 0) at time t = 0. You can move to any 4-directionally adjacent room (x, y) if current time t >= entryTime[x][y], or you must wait until entryTime[x][y]. There is no travel time between rooms. Calculate the minimum time to enter room (n-1, n-1).

#### Constraints

```
1 <= n <= 100
entryTime[0][0] = 0
0 <= entryTime[i][j] <= 10^5
```

#### Approach

This is shortest path on a weighted grid where the arrival time at neighbor (nx, ny) from (x, y) is max(currentTime, entryTime[nx][ny]). Use Dijkstra's algorithm with a min-priority queue.

#### Intuition

Finding the path that minimizes the maximum entry threshold along the way is identical to Dijkstra's minimum bottleneck path.

#### Algorithm

- Step 1: Initialize minTime[n][n] table with infinity, minTime[0][0] = 0.
- Step 2: Min-heap stores tuples (time, r, c). Push (0, 0, 0).
- Step 3: Pop node with smallest time. If reached (n-1, n-1), return time.
- Step 4: For each 4-directional neighbor (nr, nc), waitTime = max(time, entryTime[nr][nc]).
- Step 5: If waitTime < minTime[nr][nc], update minTime[nr][nc] = waitTime and push to heap.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int minEntryTime(int n, int[][] entryTime) {
        int[][] dist = new int[n][n];
        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));

        dist[0][0] = 0;
        pq.offer(new int[]{0, 0, 0});
        int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

        while (!pq.isEmpty()) {
            int[] curr = pq.poll();
            int t = curr[0], r = curr[1], c = curr[2];

            if (r == n - 1 && c == n - 1) return t;
            if (t > dist[r][c]) continue;

            for (int[] d : dirs) {
                int nr = r + d[0];
                int nc = c + d[1];
                if (nr >= 0 && nr < n && nc >= 0 && nc < n) {
                    int nextTime = Math.max(t, entryTime[nr][nc]);
                    if (nextTime < dist[nr][nc]) {
                        dist[nr][nc] = nextTime;
                        pq.offer(new int[]{nextTime, nr, nc});
                    }
                }
            }
        }
        return dist[n - 1][n - 1];
    }
}
```

- **Time Complexity:** O(N^2 * log(N))
- **Space Complexity:** O(N^2)

### 4. Bilateral Cab Service / Maximum Groups

- **Companies:** Uber
- **Years:** 2024
- **Category:** Graph
- **Difficulty:** Hard
- **Type:** Coding
- **Source:** `OA-2024/Uber-IITJ.pdf`
- **Verified Link:** [Bilateral Cab Service / Maximum Groups](https://leetcode.com/problems/divide-nodes-into-the-maximum-number-of-groups/)

#### Question

A cab service company has n cities connected by bidirectional roads. Divide these cities into m groups (1-indexed) such that: each city belongs to exactly one group; and for each road (u, v), the group numbers of u and v differ by exactly 1 (|group(u) - group(v)| == 1). Find the maximum number of groups m into which the cities can be divided. Return -1 if it is impossible.

#### Constraints

```
1 <= n <= 500
1 <= edges.length <= 10^4
```

#### Approach

A graph can be partitioned into consecutive groups differing by 1 if and only if every connected component is bipartite (contains no odd cycles)! For each connected component, the maximum number of groups is the diameter of that component (max BFS depth starting from any node in the component). The total answer is the sum of maximum groups over all connected components.

#### Intuition

The condition |group(u) - group(v)| == 1 requires the graph to be bipartite. The maximum number of levels in a BFS layering of a connected component is the maximum shortest-path distance from any vertex in that component.

#### Algorithm

- Step 1: Check if the graph is bipartite using 2-coloring. If any odd cycle exists, return -1.
- Step 2: For each connected component, find all nodes belonging to it.
- Step 3: For each node v in the component, run BFS to compute max depth from v.
- Step 4: Take the maximum depth over all nodes in the component as max_groups for that component.
- Step 5: Sum max_groups across all connected components and return the total.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int magnificentSets(int n, int[][] edges) {
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i <= n; i++) adj.add(new ArrayList<>());
        for (int[] e : edges) {
            adj.get(e[0]).add(e[1]);
            adj.get(e[1]).add(e[0]);
        }

        int[] color = new int[n + 1];
        List<List<Integer>> components = new ArrayList<>();
        boolean[] visited = new boolean[n + 1];

        // Step 1: Check bipartiteness & collect components
        for (int i = 1; i <= n; i++) {
            if (!visited[i]) {
                List<Integer> comp = new ArrayList<>();
                if (!isBipartite(i, adj, color, visited, comp)) return -1;
                components.add(comp);
            }
        }

        // Step 2: For each component, find max BFS depth
        int totalGroups = 0;
        for (List<Integer> comp : components) {
            int maxDepth = 0;
            for (int node : comp) {
                maxDepth = Math.max(maxDepth, bfsDepth(node, adj, n));
            }
            totalGroups += maxDepth;
        }
        return totalGroups;
    }

    private static boolean isBipartite(int start, List<List<Integer>> adj, int[] color, boolean[] visited, List<Integer> comp) {
        Queue<Integer> q = new LinkedList<>();
        q.offer(start);
        color[start] = 1;
        visited[start] = true;
        comp.add(start);

        while (!q.isEmpty()) {
            int u = q.poll();
            for (int v : adj.get(u)) {
                if (!visited[v]) {
                    visited[v] = true;
                    color[v] = -color[u];
                    comp.add(v);
                    q.offer(v);
                } else if (color[v] == color[u]) {
                    return false; // Odd cycle detected
                }
            }
        }
        return true;
    }

    private static int bfsDepth(int start, List<List<Integer>> adj, int n) {
        Queue<Integer> q = new LinkedList<>();
        boolean[] vis = new boolean[n + 1];
        q.offer(start);
        vis[start] = true;
        int depth = 0;

        while (!q.isEmpty()) {
            depth++;
            int size = q.size();
            for (int i = 0; i < size; i++) {
                int u = q.poll();
                for (int v : adj.get(u)) {
                    if (!vis[v]) {
                        vis[v] = true;
                        q.offer(v);
                    }
                }
            }
        }
        return depth;
    }
}
```

#### Complexity

- **Time Complexity:** O(N * (N + M))
- **Space Complexity:** O(N + M)

- **Output:** `4`

**Test Case 2:**
- **Input:** `n = 3, edges = [[1,2],[2,3],[3,1]]`
- **Output:** `-1`

### 1. Ship Locks

- **Companies:** Throughput, UiPath
- **Years:** 2024, 2025
- **Category:** Math
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `drive-download-20260904T140427Z-1-001/2025_08_30 Throughput.pdf; OA-2024/UIPath-IITG-Intern.pdf`
- **Verified Link:** [Ship Locks](https://leetcode.com/problems/minimum-moves-to-equal-array-elements-ii/)

#### Question

A ship has n doors with locks. All doors unlock only when all locks have the same value. The array locks represents n locks, where locks[i] is the initial value of lock i. In one operation, you can change a lock's value: if value = 1, next is k or 2; if value = k, next is k-1 or 1; otherwise, current - 1 or current + 1. Find the minimum number of operations needed to make all lock values equal.

#### Constraints

```
2 <= k <= 10^9
1 <= n <= 10^5
1 <= locks[i] <= k
```

#### Approach

The locks form a circle of numbers from 1 to k, where the distance between two values x and y on the circle is min(|x - y|, k - |x - y|). We need to choose a common target lock value V in 1..k that minimizes the sum of circular distances from all locks to V. On a circle, the optimal point is one of the input points or can be solved by 'unrolling' the circle: sort the values, duplicate by adding k, and find the median of every window of size n. For each window, the median minimizes the linear distance in O(1) using prefix sums.

#### Intuition

Median minimizes L1 distance. On a circular metric of length k, unrolling the sorted array into 2n elements and taking the median of each n-length window yields the global minimum circular distance.

#### Algorithm

- Step 1: Sort array locks in ascending order.
- Step 2: Create extended array of length 2n where extended[i] = locks[i] and extended[i + n] = locks[i] + k.
- Step 3: Compute prefix sums of extended array.
- Step 4: For each window of size n starting at index i (0 <= i < n): median is at mid = i + n / 2. Calculate sum of distances to extended[mid] using prefix sums.
- Step 5: Return minimum total operations across all n windows.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static long minOperations(int k, int[] locks) {
        int n = locks.length;
        Arrays.sort(locks);

        long[] arr = new long[2 * n];
        for (int i = 0; i < n; i++) {
            arr[i] = locks[i];
            arr[i + n] = locks[i] + (long) k;
        }

        long[] pref = new long[2 * n + 1];
        for (int i = 0; i < 2 * n; i++) {
            pref[i + 1] = pref[i] + arr[i];
        }

        long minOps = Long.MAX_VALUE;
        for (int i = 0; i < n; i++) {
            int mid = i + n / 2;
            long medianVal = arr[mid];

            long leftCount = mid - i;
            long leftSum = pref[mid] - pref[i];
            long leftCost = leftCount * medianVal - leftSum;

            long rightCount = (i + n - 1) - mid;
            long rightSum = pref[i + n] - pref[mid + 1];
            long rightCost = rightSum - rightCount * medianVal;

            minOps = Math.min(minOps, leftCost + rightCost);
        }
        return minOps;
    }
}
```

- **Time Complexity:** O(n log n) time
- **Space Complexity:** O(n) space

#### Question

A line was drawn with strictly increasing points line[0..n-1] where line[0] == 0. A boy starts at line[0] and must reach line[n-1]. The first hop must be 1 unit. If the last hop was t units, the next hop must be t - 1, t, or t + 1 units (forward only). Return true if the boy can reach the last point, else false.

#### Constraints

```
2 <= n <= 2000
0 <= line[i] <= 2^31 - 1
line is strictly increasing with line[0] = 0
```

#### Approach

This is LeetCode 403: 'Frog Jump'. Store positions in a HashSet or Map from position to set of jump lengths. For each stone, iterate over its reachable jump sizes k. For each jump size, next_stone = stone + k. If next_stone is in the stone map, add {k-1, k, k+1} to stone map at next_stone. If the last stone receives any jump, return true.

#### Intuition

At each stone, track all valid incoming jump lengths to determine allowable forward moves.

#### Algorithm

- Step 1: Map each stone position to a Set<Integer> of valid incoming jump lengths.
- Step 2: Initialize map.get(0).add(0).
- Step 3: For each stone position: for each jump k in map.get(stone):
- Step 4: For nextJump in {k-1, k, k+1}: if nextJump > 0 and map.containsKey(stone + nextJump), add nextJump to map.get(stone + nextJump).

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static boolean canCross(int[] stones) {
        int n = stones.length;
        Map<Integer, Set<Integer>> map = new HashMap<>();
        for (int s : stones) map.put(s, new HashSet<>());
        map.get(0).add(0);

        for (int i = 0; i < n; i++) {
            int stone = stones[i];
            for (int k : map.get(stone)) {
                for (int step = k - 1; step <= k + 1; step++) {
                    if (step > 0 && map.containsKey(stone + step)) {
                        map.get(stone + step).add(step);
                    }
                }
            }
        }
        return !map.get(stones[n - 1]).isEmpty();
    }
}
```

### 2. Largest Square in Cityline

- **Companies:** Visa
- **Years:** 2025
- **Category:** Stack
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `drive-download-20260904T140427Z-1-001/2025_09_12_Visa.pdf`
- **Verified Link:** [Largest Square in Cityline](https://leetcode.com/problems/largest-rectangle-in-histogram/)

#### Question

You are given an array cityLine representing heights of skyscrapers, each of width 1. Return the area of the largest square that can fit within the skyscrapers along the road.

#### Constraints

```
1 <= cityLine.length <= 10^6
1 <= cityLine[i] <= 10^6
```

#### Approach

For each bar i, find the maximum width of a rectangle with height cityLine[i] using monotonic stack (previous smaller and next smaller element). If the available width is W and height is H = cityLine[i], the side length of the largest square inside this rectangle is min(W, H). The maximum square area is max(min(W, H)^2). Alternatively, binary search on square side length L: check if there exists a contiguous subarray of length L where all heights >= L.

#### Intuition

A square of side L requires a contiguous segment of length at least L where every skyscraper has height >= L.

#### Algorithm

- Step 1: Compute previous smaller element (PSE) and next smaller element (NSE) for each index using a monotonic stack.
- Step 2: For each skyscraper i, width = NSE[i] - PSE[i] - 1.
- Step 3: Side length of square fitting in this bar's rectangle is side = min(width, cityLine[i]).
- Step 4: Track maxSide = max(maxSide, side).
- Step 5: Return maxSide * maxSide as a 64-bit integer.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static long largestSquareArea(int[] cityLine) {
        int n = cityLine.length;
        int[] pse = new int[n];
        int[] nse = new int[n];
        Stack<Integer> st = new Stack<>();

        for (int i = 0; i < n; i++) {
            while (!st.isEmpty() && cityLine[st.peek()] >= cityLine[i]) st.pop();
            pse[i] = st.isEmpty() ? -1 : st.peek();
            st.push(i);
        }

        st.clear();
        for (int i = n - 1; i >= 0; i--) {
            while (!st.isEmpty() && cityLine[st.peek()] >= cityLine[i]) st.pop();
            nse[i] = st.isEmpty() ? n : st.peek();
            st.push(i);
        }

        long maxSide = 0;
        for (int i = 0; i < n; i++) {
            long width = nse[i] - pse[i] - 1;
            long side = Math.min(width, (long) cityLine[i]);
            maxSide = Math.max(maxSide, side);
        }
        return maxSide * maxSide;
    }
}
```

### 3. Molecular Reactor Synthesis Time

- **Companies:** Visa
- **Years:** 2025
- **Category:** Queue
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `drive-download-20260904T140427Z-1-001/2025_09_12_Visa.pdf`
- **Verified Link:** [Molecular Reactor Synthesis Time](https://leetcode.com/discuss/interview-question/5759902/Visa-OA-2025)

#### Question

A molecular research reactor synthesizes complex compounds. Each reaction takes exactly 300 seconds (5 minutes). The reactor can only process one sample at a time. Samples waiting to be processed wait in a cooling chamber of capacity 10. If newly arriving sample arrives when chamber already holds 10 waiting samples, it is rejected. Return the total time required to process all accepted samples in seconds since start of operating day.

#### Constraints

```
1 <= times.length <= 1000
0 <= times[i] <= 5 * 10^4
times is strictly increasing
```

#### Approach

Simulate the events using a queue representing the cooling chamber. Track reactorFinishTime. When sample arrives at time T: if reactor is idle (reactorFinishTime <= T), it starts processing immediately, so reactorFinishTime = T + 300. Otherwise, if reactor is busy, but previous waiting samples finished while time progressed, process them from cooling chamber. If cooling chamber currently has < 10 samples, accept and push into chamber; else reject.

#### Intuition

Carefully simulate the sequential queue operations with capacity limits and reaction duration 300s.

#### Algorithm

- Step 1: Initialize reactorFreeTime = 0, queue of accepted arrival times.
- Step 2: For each arriving sample time T: while queue not empty and reactorFreeTime <= T, pop sample, advance reactorFreeTime = max(reactorFreeTime, popped_time) + 300.
- Step 3: Determine how many samples are currently waiting in cooling chamber between T and reactorFreeTime.
- Step 4: If waiting samples < 10, accept sample and push; else reject.
- Step 5: Process all remaining accepted samples in the queue until empty. Return reactorFreeTime.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static int totalProcessingTime(int[] times) {
        long reactorFree = 0;
        Queue<Long> chamber = new LinkedList<>();

        for (int t : times) {
            // Process finished samples up to time t
            while (!chamber.isEmpty() && reactorFree <= t) {
                long sampleArrival = chamber.poll();
                reactorFree = Math.max(reactorFree, sampleArrival) + 300;
            }

            // If reactor is free now, start immediately
            if (reactorFree <= t) {
                reactorFree = t + 300;
            } else {
                // Check cooling chamber capacity (max 10 waiting)
                if (chamber.size() < 10) {
                    chamber.offer((long) t);
                }
                // else rejected
            }
        }

        // Finish remaining samples in cooling chamber
        while (!chamber.isEmpty()) {
            long sampleArrival = chamber.poll();
            reactorFree = Math.max(reactorFree, sampleArrival) + 300;
        }

        return (int) reactorFree;
    }
}
```

#### Complexity

- **Time Complexity:** O(N) simulation
- **Space Complexity:** O(capacity) = O(10) space

#### Sample Test Cases

**Test Case 1:**
- **Input:** `times = [1, 6, 9, 502]`
- **Output:** `1201`

### 1. Total Divisors of Printer Pages

- **Companies:** Walmart
- **Years:** 2024

- **Difficulty:** Easy
- **Type:** Coding
- **Source:** `OA-2024/walmart-bits-h-24.pdf`
- **Verified Link:** [Total Divisors of Printer Pages](https://practice.geeksforgeeks.org/problems/count-divisors-of-factorial-of-a-number/1)

#### Question

A network is connected to N printers. The ith printer is set to print a number of pages equal to the total number of factors (divisors) of integer A[i]. Determine the number of pages printed from each printer.

#### Constraints

```
1 <= N <= 50,000
1 <= A[i] <= 100,000
```

#### Approach

Precompute the number of divisors for all numbers up to max(A) <= 100,000 using a sieve-like approach in O(M log M) where M = 100,000. For each query A[i], answer in O(1) time.

#### Intuition

Precomputing divisor counts using a sieve allows O(1) query time for each of the 50,000 printers.

#### Algorithm

- Step 1: Create an array numDivisors of size 100,001 initialized to 0.
- Step 2: For i from 1 to 100,000: for j from i to 100,000 step i: numDivisors[j]++.
- Step 3: For each printer page requirement A[i], look up numDivisors[A[i]].
- Step 4: Return the array of answers.

#### Java Solution

```java
import java.util.*;

public class Solution {
    static int[] divisors = new int[100001];
    static {
        for (int i = 1; i <= 100000; i++) {
            for (int j = i; j <= 100000; j += i) {
                divisors[j]++;
            }
        }
    }

    public static int[] totalDivisors(int n, int[] arr) {
        int[] result = new int[n];
        for (int i = 0; i < n; i++) {
            result[i] = divisors[arr[i]];
        }
        return result;
    }
}
```

#### Complexity

- **Time Complexity:** O(M log M + N) where M = 10^5
- **Space Complexity:** O(M) for sieve lookup

### 2. Robot Alex Speech Processing

- **Companies:** Walmart
- **Years:** 2024
- **Category:** Strings
- **Difficulty:** Easy
- **Type:** Coding
- **Source:** `OA-2024/walmart-bits-h-24.pdf`
- **Verified Link:** [Robot Alex Speech Processing](https://leetcode.com/problems/reverse-vowels-of-a-string/)

#### Question

A robot Alex processes spoken sentences: 1) If a vowel is immediately followed by a consonant, exchange their positions. 2) Next alphabet traversal continues after the exchanged vowel. 3) No exchange if consonant is followed by vowel or both are vowels/consonants. 4) All special characters and spaces are removed. Print the resultant string.

#### Constraints

```
Length of input string < 100
Contains alphanumeric characters, spaces, and special symbols
```

#### Approach

First, filter the string by keeping only alphanumeric characters (letters and digits). Then traverse the cleaned characters: if char at i is a vowel and char at i+1 is a consonant, swap them and advance past the pair (i += 2); otherwise, advance i by 1.

#### Intuition

Filter first to remove punctuation and whitespace, then perform pairwise vowel-consonant adjacent swaps.

#### Algorithm

- Step 1: Remove all spaces and special characters, retaining only letters and digits.
- Step 2: Convert to character array.
- Step 3: Loop i from 0 to len - 2: if isVowel(arr[i]) and isConsonant(arr[i+1]), swap arr[i] and arr[i+1], i++.
- Step 4: Return resulting string.

#### Java Solution

```java
public class Solution {
    public static String processSpeech(String s) {
        StringBuilder clean = new StringBuilder();
        for (char c : s.toCharArray()) {
            if (Character.isLetterOrDigit(c)) {
                clean.append(c);
            }
        }

        char[] arr = clean.toString().toCharArray();
        int i = 0;
        while (i < arr.length - 1) {
            if (isVowel(arr[i]) && isConsonant(arr[i + 1])) {
                char tmp = arr[i];
                arr[i] = arr[i + 1];
                arr[i + 1] = tmp;
                i += 2;
            } else {
                i++;
            }
        }
        return new String(arr);
    }

    private static boolean isVowel(char c) {
        c = Character.toLowerCase(c);
        return c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u';
    }

    private static boolean isConsonant(char c) {
        return Character.isLetter(c) && !isVowel(c);
    }
}
```

#### Complexity

- **Time Complexity:** O(N) time
- **Space Complexity:** O(N) space

**Test Case 1:**
- **Input:** `s = "Barbara likes this"`
- **Output:** `Brbaraalkisethsi`

**Test Case 2:**
- **Input:** `s = "You are 2 g00d @ coding."`
- **Output:** `Yourae2g00dcdongi`

### 1. Valid BFS Tree Traversal

- **Companies:** Zomato
- **Years:** 2024
- **Category:** Graph
- **Difficulty:** Medium
- **Type:** Coding
- **Source:** `CDC Placement Preparations 2025-2026.xlsx`
- **Verified Link:** [Valid BFS Tree Traversal](https://codeforces.com/problemset/problem/1037/D)

#### Question

Given an undirected tree with n nodes and an array a of length n representing a sequence of vertices. Determine if the sequence a can represent a valid Breadth First Search (BFS) traversal of the tree starting from vertex 1.

#### Constraints

```
1 <= n <= 2 * 10^5
1 <= u, v <= n
a is a permutation of 1 to n with a[0] == 1
```

#### Approach

In a standard BFS, the children of a node u can be visited in any order. However, all children of node u must appear in the BFS sequence before the children of any node enqueued after u! For each vertex, sort its adjacency list according to the relative order of appearance in array a. Then perform a standard BFS from node 1. The resulting BFS traversal must match array a exactly.

#### Intuition

Sorting each node's children based on their order in the candidate sequence forces BFS to greedily follow the target order if valid.

#### Algorithm

- Step 1: If a[0] != 1, return false.
- Step 2: Map each vertex to its position in array a: pos[a[i]] = i.
- Step 3: For every node u, sort its neighbors by pos[neighbor].
- Step 4: Run standard BFS starting at 1, recording the visit order.
- Step 5: Check if the generated BFS order matches array a element by element. If yes return true, else false.

#### Java Solution

```java
import java.util.*;

public class Solution {
    public static boolean validBFS(int n, int[][] edges, int[] a) {
        if (a[0] != 1) return false;
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i <= n; i++) adj.add(new ArrayList<>());
        for (int[] e : edges) {
            adj.get(e[0]).add(e[1]);
            adj.get(e[1]).add(e[0]);
        }

        int[] pos = new int[n + 1];
        for (int i = 0; i < n; i++) pos[a[i]] = i;

        for (int i = 1; i <= n; i++) {
            adj.get(i).sort(Comparator.comparingInt(x -> pos[x]));
        }

        boolean[] visited = new boolean[n + 1];
        Queue<Integer> q = new LinkedList<>();
        q.offer(1);
        visited[1] = true;
        int idx = 0;

        while (!q.isEmpty()) {
            int u = q.poll();
            if (a[idx++] != u) return false;

            for (int v : adj.get(u)) {
                if (!visited[v]) {
                    visited[v] = true;
                    q.offer(v);
                }
            }
        }
        return idx == n;
    }
}
```

#### Complexity

- **Time Complexity:** O(N log N) sorting neighbors
- **Space Complexity:** O(N) space

#### Sample Test Cases

**Test Case 1:**
- **Input:** `n = 4, edges = [[1,2],[1,3],[2,4]], a = [1, 2, 3, 4]`
- **Output:** `true`

**Test Case 2:**
- **Input:** `n = 4, edges = [[1,2],[1,3],[2,4]], a = [1, 2, 4, 3]`
- **Output:** `false`
